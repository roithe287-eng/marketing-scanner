# 마케팅스캐너 GEO 개발 기획안

작성일: 2026-10-01 · 기준: GEO 기대효과와 최적화 수행 방안 12장 및 현재 서비스 코드

## 목표와 사용자 흐름

고객이 묻는 질문 → AI 답변과 실제 출처 확인 → 우리 페이지와 연결 → 콘텐츠 개선 → 같은 질문으로 재측정한다. 단일 URL 진단을 출발점으로 삼으며, 사이트 전체의 콘텐츠 유무나 답변 정확도를 확인 없이 단정하지 않는다.

## 이번 개발 범위

| 영역 | 구현 내용 | 완료 기준 |
| --- | --- | --- |
| 질문 | 고객 여정별 기본 질문, 직접 입력한 최대 5개 질문, 질문 세트 식별자 | 동일 입력의 질문 재사용, 브랜드 포함 질문 구분 |
| AI 측정 | OpenAI 웹 검색·Gemini 검색 출처 수집, 답변 원문·모델·측정시각 저장 | 브랜드 언급과 자사 URL 인용 분리, 실패·검색 미확인 분모 제외 |
| 실행 과제 | 질문별 인용 페이지 또는 확인한 입력 페이지 연결, 유지·개선·신규 검토 제안 | 관측 근거와 미확인 범위를 함께 표시, 정확도는 검토 필요 표시 |

| 품질 | 타입·빌드·회귀 테스트, 실제 미리보기 분석→공유→PDF | 정상·빈값·실패·긴 답변·기존 리포트 확인, 발견한 결함 수정 후 재검증 |

## 지표 정의

- 브랜드 언급률: 답변 본문에 브랜드/정확한 도메인이 등장한 정상 응답 / 정상 응답.
- 자사 출처 인용률: 검색 출처 메타데이터에서 자사 호스트·하위 도메인이 확인된 응답 / 검색 수행과 출처 판정이 확인된 응답.
- 브랜드 포함/미포함 질문은 분리 표시. 0건 측정은 0%가 아니라 측정 불가.
- 오류·시간 초과·미설정·검색 미확인은 별도 상태. 답변 목록 번호를 검색 순위로 표시하지 않는다.
- API 관측이며 일반 ChatGPT/Gemini 화면이나 시장 전체 노출률을 의미하지 않는다.
- URL 인용과 매출 증가의 인과관계, AI 답변의 사실 정확도는 자동 보증하지 않는다.

## 후속 단계

1. 프로젝트별 고정 질문·고객 승인 사실 정보·담당자·완료 상태와 변경 이력 저장.
2. 다중 페이지 수집 후 기존 페이지 개선/신규 생성 판단을 강화하고, 경쟁사·미디어·커뮤니티 출처를 별도 분류.
3. 동일 조건 반복 관측 및 기간 비교, Search Console/GA4 실제 방문·전환 연결. 자동 정기 측정은 별도 비용·실행 주기를 정한 뒤 도입.

이번 범위에 자동 게시, 프롬프트 인젝션, 검증되지 않은 매출 예측, llms.txt 부재에 대한 과도한 감점을 포함하지 않는다.

## 검증과 배포 원칙

- 기존 리포트 스키마는 계속 열리며, 기존의 언급 기반 수치는 구버전 측정임을 명시한다.
- 운영 IP 제한은 유지하고 필요시 작업 브랜치의 미리보기만 만료 시각을 두고 임시 허용한다. 검증 종료 후 해당 임시 코드를 제거한다.
- 공유 결과와 PDF는 생성 시점의 데이터 스냅샷이다. 경쟁사 분석이 진행 중이면 완료 상태가 확정된 뒤 내보낸다.
- 테스트 결과·실제 확인 범위와 미확인 사항은 배포 검증 기록에 남긴다.
