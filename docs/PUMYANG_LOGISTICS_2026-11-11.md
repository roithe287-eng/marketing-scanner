# 범양해운·국제물류 분석 보완

대상: https://www.pumyang.com/ · 2026-11-11 (한국시간)

## 확인한 문제와 변경

- 기존 운영 진단은 HTML 수집에 성공했으나 일반 서비스·상담형과 추상적인 고객 질문을 사용했다.
- 현재 원문 신호에 근거한 `international_logistics` 프로필과 `logistics` 업종을 추가했다. 해외·귀국이사와 기업 수출입 화물을 구분하며 운송 조건 확인·견적 상담을 목표로 삼는다. 도메인만으로 업종이나 점수를 부여하지 않는다.
- 메인 원문에 더해 해외이사 절차, 해상운송, 상담신청 페이지를 최대 3개 보완 수집한다. 동일 사이트·robots·시간 제한을 유지하고 보완 원문을 메인 H1·메타·CTA 측정값에 합산하지 않는다.
- 출발·도착지, 물량·일정, 포함·추가 비용, 포장·통관·인도, 보험·보상, 담당 거점에 맞춘 점검·질문·GEO·키워드·경쟁사 기준을 연결했다.
- 상담 양식은 공개 라벨만 수집한다. 입력값·숨김 필드·개인정보처리방침과 모달은 서비스 근거에서 제외한다. 운송 약관·기간·가격 답변에는 후기 제거 후 수집한 사업자 안내를 사용한다.
- 문의를 포함한 긴 공지 링크를 상담 CTA로 해석하지 않고, 실제 메뉴의 상담신청 링크를 관측한다.
- HTTP 406은 요청 형식 거부로 구분해 점수 없는 제한 결과로 처리한다. 다른 호스트나 HTTP로 재시도하지 않는다. 일반 GET 수집 성공과 HEAD/외부 수집 환경의 제한 응답은 구분해야 한다.

## 검증

- 전체 자동 테스트 517개 통과, TypeScript 검사 통과, 로컬 프로덕션 빌드 성공.
- 실제 공개 HTML(메인·해외이사 절차·상담신청)을 추출기로 재생해 전용 업종·상담 CTA·질문·라벨 출처를 확인했다.
- 공개 검색 요약은 원문 근거로 승격하지 않는다. 운송기간·통관 가능 여부·보상 및 실제 문의 접수·계약 전환은 검증하지 않았다.
- 배포 후 운영 사이트에서 같은 URL로 새 진단을 실행해 최종 결과를 확인한다. 이전 저장 보고서는 자동으로 다시 쓰지 않는다.

## 운영 재진단 후 보완

- 운영 배포에서 전용 업종, 실제 상담 양식 라벨, 포장·통관 절차와 보험보상 안내의 원문 연결을 확인했다.
- 해외이사 검색에 섞인 생활법령·법령정보 출처를 서비스 제공 업체와 구분한다. 해당 출처는 비교 후보에서 제외하며, 공공 도메인 전체를 배제하지 않는다.
- 서비스·커뮤니티에서 수행하지 않은 상품 수집을 ‘상품 원문 미확인’으로 표시하지 않도록 연구 결과에서 생략한다. 상세 원문이 불완전하더라도 메인 원문으로 확인한 업종은 유지한다.
- 전체 자동 테스트 519개와 TypeScript 검사를 후속 검증한다. 운영 재진단은 개인 문의 폼 제출 없이 공개 정보만 사용한다.

## 상세 분석 확장

- 범양해운의 공개 수집 범위를 메인과 상세 7개로 확장한다. 해외·귀국이사, 해상·항공운송, 보관, 상담 양식, 운송약관을 같은 시간 예산에서 최대 3개씩 병렬 수집하며 robots와 개인정보 제외 규칙을 유지한다.
- `serviceStrategy`는 수집한 자사 원문에서 확인한 서비스만 포함한다. 4개 집중 점검, 서비스별 고객 가설·선택 질문·검색어·6단계 랜딩 구성·문구·성과 기준, 4개 채널 실행안, 콘텐츠 기획, 5단계 전환·5개 KPI, 4주 실행안을 제공한다. 검색량·광고 실적을 추정하거나 점수를 가산하지 않는다.
- 질문을 8개로 확장하고 현재 원문과 해석·보완 방향 및 답변 작성안을 구분한다. 홈페이지 메타와 공개 폼 라벨에 기반한 관측을 실제 광고·폼 동작에 대한 판단과 구분한다.
- 기존 보고서의 요약·검색·실행 장에 상세 섹션 4개를 순차로 배치하며 PDF·HTML·Markdown에도 동일한 내용을 포함한다. 기존 저장 보고서는 유지하고 새 진단부터 적용한다.
- 국제물류에만 AI 상세 모드를 적용한다. 최대 6개 이슈·5개 빠른 개선과 보다 구체적인 권고를 허용하되 기존 시간 제한과 실패 시 대체 경로를 유지한다.
- 전체 테스트 524개 및 배포용 빌드 통과. 실제 공개 HTML 8개 재생에서 서비스 5개·상세 질문 8개와 원문 연결을 확인했다.

## 네이버 AI 브리핑 검색 사례 대응

- 제공된 해외이사 검색 화면의 요약·5단계 절차·준비 체크리스트·업체 선정 기준·이미지/블로그 출처 구조를 참고한 제안이다. 첨부 이미지나 제3자 게시물은 배포하지 않으며, 촬영 시점·검색 조건·전체 출처 URL을 확인한 실시간 관측으로 취급하지 않는다.
- 자사 HTML에서 해외이사 원문을 확인한 경우에만 `serviceStrategy.briefing`을 추가한다. 4개 답변 영역별 원문 단서/추가 검토/적용 위치/작성 초안, 5단계별 고객 준비·업체 역할, 홈페이지·블로그·사진 역할, 블로그 6편 기획, 발행·인용·유효 문의 검증을 구분한다.
- 메인 메뉴에서 확인한 `/oversea/03/` 체크리스트도 보완 수집에 포함한다. 범양해운은 메인+상세 8개를 같은 6초 예산·동시 요청 최대 3개 기준으로 수집한다. 일반적인 홈페이지 문구보다 실제 상세 원문의 근거를 우선한다.
- 원문 단서 판정은 본문의 표현 기준이며 제목만으로 충족하지 않는다. 미확인은 사이트 전체 부재를 뜻하지 않는다. 타 사이트·후기·검색 요약은 자사 운영 사실을 채우지 못한다. 예시 화면의 준비 기간·브랜드별 순위·노출 성과는 전용 템플릿의 사실로 복사하지 않는다.
- 공식 참고 자료: https://searchadvisor.naver.com/guide/content-basic 및 https://www.navercorp.com/service/search . 일반 콘텐츠 품질 안내를 AI 브리핑 선정 공식으로 해석하지 않는다.
- 보고서의 AI·GEO 장에 펼쳐진 상세 항목을 배치하고 PDF·HTML·Markdown에도 포함한다. 기존 저장 보고서의 선택 필드 호환성을 유지하며 별도 외부 API 호출이나 시간 예산은 추가하지 않는다.
- 전체 테스트 530개와 TypeScript 검사를 통과했다. 실제 범양해운 공개 HTML 재생으로 원문 연결과 범위별 추가 검토 항목을 확인한다.
