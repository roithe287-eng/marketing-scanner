# 마케팅스캐너 추가 안정성·가독성 검증

2026-10-05 · 이전 PR #54 이후의 웹사이트 후속 점검. 소비자 앱 소스와 운영 접근 정책은 변경하지 않았다.

## 발견한 문제와 수정

| 대상 | 확인한 위험 | 반영한 처리 |
| --- | --- | --- |
| 반복어 빈도 | 본문에 포함된 H1/H2를 다시 더하고 제목·설명을 합산하여 본문 빈도로 오해할 수 있음 | 수집 본문만 1회 집계. 제목·메타 설명은 포함 여부를 별도 검사 |
| 연속어구 | 문장·HTML 블록 경계, 제외 단어와 짧은 단어를 건너 실제로 연속하지 않은 표현을 생성할 수 있음 | 원래 인접한 토큰과 공백만 허용. 문장부호·줄바꿈·블록·제외 단어를 건너 연결하지 않음 |
| HTML 텍스트 추출 | 인접한 문단·제목이 공백 없이 붙을 수 있음 | 블록과 BR 경계를 줄바꿈으로 보존. 인라인 강조 문구의 연속성은 유지 |
| 비중 표시 | 가장 빈번한 표현을 100% 길이로 그리면서 다른 기준의 비중 숫자를 함께 표시 | 막대 전체를 100%로 고정하고 실제 비중에 비례. 단어와 어구 각각의 분모 공개 |
| 잘못된 빈도 입력 | 음수·소수 횟수, 무한대, 100% 초과 비중의 스키마 통과 가능 | 유효 범위를 벗어나면 결과 검증 단계에서 거부 |
| 네이버 공용 도메인 | `ca-fe` 공통 경로 또는 Place 호스트만으로 다른 업체를 같은 대상으로 판정할 가능성 | 카페·Place의 개별 ID 확인. 식별할 수 없는 경로는 동일 대상으로 확정하지 않음 |
| GEO 계산·실행 제안 | 판정 불가 상태에 오래된 성공 플래그가 남으면 계산·실행 제안에 섞일 가능성 | 정상·검색 확인·출처 확인·중복 아님을 함께 검사. 실패/중복/미확인은 재측정 대상으로 처리 |
| 측정 상태 | 미설정이 호출 실패와 동일한 상태로 표시됨 | 미설정·호출 실패·판정 불가·관측 없음·미인용을 구분 |
| 과거 결과 | 계산·식별 방식 변경을 성과 변화로 오해할 가능성 | 진단 방식 v4, GEO 비교 규칙 v3, 캐시 버전 갱신. 서로 다른 방식 간 직접 비교 보류. 이전 GEO는 저장 원문으로만 재검토 |

빈도 스코프와 이전 방식 주의 문구는 화면의 원시 집계·TO-BE와 상세 PDF 문서에 함께 반영했다. HTML 본문에는 메뉴·푸터가 포함될 수 있으며, 동적 렌더링 문구와 수집 상한 밖의 본문은 포함되지 않을 수 있다. 단어 빈도는 검색량이나 적정 키워드 밀도가 아니다.

## 시각적 변경

- 보고서 상단을 `수집 관측 → AI 해석 → 실행 제안`의 세 카드로 구성했다. 근거 대조 범위와 재확인 대상은 펼쳐서 읽을 수 있다.
- 제목·문제·원인·조치의 크기와 굵기를 구분하고 긴 문장은 전체를 유지했다.
- 작은 보조 글씨와 파스텔 배경 위의 대비를 개선했다. 핵심 본문은 16px, 주요 메타 정보는 14px를 사용한다. 일부 차트·장식·보조 표시는 기존 크기를 유지한다.
- 모바일 키워드 표를 한 표현씩 읽는 카드 배열로 변경했다. 제목·설명 포함 여부는 색상과 함께 `포함/미포함`으로 표기한다.
- 좁은 화면에서 목차를 일반 문서 흐름으로 배치하여 고정 목차가 본문을 크게 가리지 않게 했다. PC의 고정 목차와 키보드 포커스 표시를 유지했다.

## 검증

- 단위·회귀 테스트 **173개 통과**. 본문 중복, 실제 인접 어구, 경계 문자, 이전/부분 집계, 플랫폼 ID, 판정 불가, 잘못된 수치의 회귀 사례 포함.
- 실제 Redis 통합 **5개 통과**. 요청 제한의 원자성, 문의→승인→활성화→로그인→비공개 결과→정지, 저장 실패 시 권한 거부, 표본 중복 제거·만료·측정 방식 분리, 보고서와 소유자 인덱스 원자 저장 확인.
- 프로덕션 웹 빌드·타입 검사 통과.
- 브라우저 안정성 **8개 흐름 통과**. 중복 제출, 잘못된 JSON/게이트웨이 응답, 이전 결과 보존, 취소된 경쟁사 응답, 저장 실패 후 재시도, 경쟁사 상세 변경, 구버전 표본 보류, 접근 정보 오류 시 차단을 확인.
- 로컬 프로덕션 빌드에 합성 API 응답을 연결해 상세 결과를 확인했다. **320·390·768·1440px**에서 페이지 전체의 가로 넘침 없음. **390px에서 글자 200% 확대** 후에도 페이지 전체 가로 넘침 없음. 긴 이슈 본문이 손실 없이 남는지 확인.
- 동일한 상세 예시에서 화면에 표시된 일반 HTML 텍스트의 계산상 저대비 항목은 **94개 → 0개**. 이 검사는 그라데이션·SVG·숨긴 내용·비활성 컨트롤을 제외한 제한된 검사이며, 모든 화면/상태의 접근성 인증이나 무결성을 뜻하지 않는다.
- PC 근거 카드·레이더·준비도 점검판, 모바일 긴 이슈·키워드 카드·200% 확대 화면을 캡처해 확인했다.

검증 코드는 `tests/additional-integrity.test.ts`, `tests/browser/readability.cjs`, `tests/browser/web-stability.cjs`에 보관했다. 합성 데이터는 `tests/fixtures/rich-report.ts`에만 있으며 운영 경로에서 사용하지 않는다.

## 공식 기준과 한계

가독성 점검 기준: [W3C 대비](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [글자 확대](https://www.w3.org/WAI/WCAG21/Understanding/resize-text), [리플로](https://www.w3.org/WAI/WCAG21/Understanding/reflow). 2026-10-05 확인. 전체 WCAG 준수를 인증한 것은 아니다.

승인된 운영 진단 계정이 없어 실제 인증 사용자로 네이버·OpenAI·Gemini를 호출하는 전체 운영 흐름은 실행하지 못했다. 운영 IP·계정 정책을 우회하지 않았으며, 외부 서비스의 현재 응답 성공률을 이 검증으로 보장하지 않는다.

원문 일치와 계산 규칙 검증은 사이트가 주장하는 사실이나 AI 해석 전체의 진실성을 입증하지 않는다. 기대효과는 공식 원리에 따른 검토 제안이며 해당 사이트의 인과 효과·순위·전환·매출 보장이 아니다. 새 집계 방식이 필요한 이전 보고서는 재진단해야 한다.
