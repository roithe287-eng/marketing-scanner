# 병원 대상 컨설팅·마케팅 진단 보완

mcg2023.com과 www.mcg2023.com의 공개 메인, 컨설팅사업부, 마케팅사업부, 서비스 과정을 확인했다. 메인 제목·설명은 병원 전문 컨설팅·마케팅·홈페이지 제작 실행사이며, 문의 폼의 병원명·지역·상담 분야는 병원이 고객인 사업자 대상 서비스임을 뒷받침한다.

## 수정

- `medical_consulting` 선택적 업종 기준을 추가했다. 병원 대상 제공 서비스를 일반 병의원 진료와 구분하고, 마케팅 업종은 `consulting`, 다음 행동은 상담·문의로 연결한다. 특정 도메인만으로 업종을 고정하지 않는다.
- 제공 범위, 담당 조직·병원 실무 경험, 진행 절차, 사례·성과 확인 조건, 견적·계약 범위, 문의 입력·연결의 6개 기준을 기존 업종 카드·질문·프롬프트·저장 보고서·문서/PDF 경로에 전달한다. 가격 미확인은 정액 가격 부재나 실패 판정이 아니다.
- 아임웹의 body 클래스 `mobile-nav-on`, `fixed-menu-on`, `new_header_site`를 메뉴 컨테이너로 오인해 본문 전체가 탈락하던 수집 문제를 수정했다. 실제 메뉴·헤더·푸터·오버레이는 제외하고, 뒤쪽 상담 링크는 제한된 CTA 표본 안에서 우선 수집한다.
- 문의 폼은 입력 항목의 라벨만 업종 판단에 사용한다. 입력된 값·비밀번호·숨김 필드는 수집하지 않는다. 상담 버튼·폼 존재는 제출 성공이나 실제 상담 연결을 뜻하지 않는다.
- 운영 재진단에서 개인정보 동의 문단이 첫 서비스 원문으로 선택되는 문제를 추가 확인했다. 폼 내부 문단과 입력값은 별도 라벨 관측과 분리해 본문·서비스 인용 후보에서 제외한다. 법적 동의나 실제 폼 자체를 변경하는 작업은 아니다.
- 병원 컨설팅 업체에 초진·진료 예약·비급여·의료진 자격 안내를 권하는 결과를 제외하고, 잘못 생성된 진료 예약 CTA를 실제 상담 문구로 맞춘다. 실제 병원, 기사형 페이지, 기존 커머스와 기존 저장 스냅샷은 유지한다.
- 별도 기술 진단에서도 같은 구분을 사용해 컨설팅 업체에 의료기관 스키마 검토를 자동 요구하지 않는다. 이미 원문에 선언된 의료기관·의료진 엔터티는 숨기지 않고 그대로 검사한다.
- 진단 방식 버전은 `marketing-diagnosis-2026-11-v18-provider-purpose`, GEO 질문 캐시는 `geo-v3.5-provider-purpose`로 구분한다.
- 운영 검사에서 AI 응답의 필수 항목 누락 후 재시도가 시간 초과되는 사례를 확인했다. 모델이 생성할 필드만 기존 보고서 스키마에서 파생하고, Strict Structured Outputs로 필수 항목·열거값·닫힌 객체를 요청한다. 기존 서버 검증은 유지하며 검증 실패 시 원문·모델 답변 없이 필드 경로와 오류 코드만 기록한다. 모델·과금 정책·API 키는 변경하지 않는다.

## 확인 범위

현재 공개 메인 HTML을 동일한 추출 함수로 재생해 수정 전 `medical`·진료 기준에서 수정 후 `consulting`·병원 컨설팅 기준으로 바뀜을 확인한다. 수정 전 0개였던 본문 구역은 28개로 수집된다. 실제 공개 원문에서 읽은 사실이며, 폼 제출·상담 연결·광고 성과·매출은 이 검사에서 측정하지 않는다.

축약한 CMS 구조로 분류·문의 목표·본문 수집·민감한 입력값 제외·질문·저장/문서 경로의 회귀검사를 추가했다. 실제 병원과 Article의 목적 보존, 도메인 독립성도 검사한다.
