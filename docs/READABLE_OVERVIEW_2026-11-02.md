# 핵심요약의 순서와 쉬운 설명 · 2026-11-02

## 먼저 보여주는 내용

커머스·비커머스·이전 보관 보고서 모두 홈페이지 내용 → 고객 질문·답변(네이버 AI 브리핑 대응 개선안) → 우선 할 일 → 업종별 확인(해당할 때) → 영역별 진단 순서로 읽는다. 점수·원래 작업·원문·조건·상태는 유지하며 목차와 깊은 링크로 이동할 수 있다. 홈페이지 원문은 240자 이내 발췌 하나를 먼저 표시하고, 전체는 원문 모음에서 확인·복사한다.

## 설명과 도식

- 첨부 레퍼런스의 작은 브라우저 모형을 공통 SVG로 확장했다. 첫 화면·검색 결과·비용·FAQ·사례·문의 버튼·이미지·설정·진행 순서 등 9개 모형을 사용한다.
- 홈페이지 내용의 6개 관점마다 위치와 작성 틀을 짧은 도식 카드 2~3개로 보여준다. 우선 작업 최대 3개는 쉬운 제목·확인할 곳·할 일로 요약한다.
- 질문별로 서비스 설명 → 질문과 답변 → 다음 행동 배치를 보여준다. 키워드 선정 근거는 질문 뒤로 이동하고 전체 기록은 유지한다.
- H1·CTA·alt·canonical·구조화 데이터 등 17개 안내 주제에 쉬운 설명과 도식을 제공한다. 네이버 점검·공통 검색 점검·상세 실행 가이드에 공통 적용한다.
- 화면 모형은 ‘구성 예시 · 실제 화면 캡처 아님’으로 표시한다. 실제 사이트 수정 완료나 AI 노출을 의미하지 않는다. 작은 화면은 두 열과 전폭 마지막 카드를 사용한다.

## 근거 오분류 수정

사업자등록번호·통신판매 신고번호의 실제 번호, 영문 저작권·약관·개인정보 정책 등 회사 하단 정보를 서비스·지원 근거에서 제외한다. 원문 모음에서는 계속 보존한다. ‘사업자등록번호가 있는 신청자’ 같은 자격 안내는 제외하지 않는다. 순수 버튼 문구만으로 서비스 내용이 설명됐다고 분류하지 않는다. 상품·제작·판매·유니폼·의류와 ‘10,000원’ 같은 금액 표기도 연결한다.

## 검증

전체 회귀 검사 419개, TypeScript 검사 및 포켓 앱을 포함한 운영 빌드. 순서·중복·깊은 링크·데이터 불변성·원문 유지·푸터 오분류·짧은 작업 카드·SVG·예시 표시·HTML 이스케이프를 검사한다. 화면 검수는 기존 미리보기 전용 `/review/report?frame=1&sample=service`의 가상 자료를 사용하며 운영에서는 이 경로가 비활성이다.

저장 스키마·API·접근 권한·결제·보관 정책·AI 모델·사용량·수집 요청은 변경하지 않는다.
