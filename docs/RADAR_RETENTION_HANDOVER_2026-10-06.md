# 마케팅스캐너 작업 이어가기 · 2026-10-06

## 반영 범위

- Gemini API 호출과 결과 표시 제거. 과거 공유 결과는 OpenAI 관측만 다시 집계하며, 새 측정처럼 표시하지 않는다. 화면·상세 PDF·시각 PDF·이전 결과 비교에 같은 기준을 사용한다.
- 레이더 라벨 박스 86×30 → 64×24, 글자 18 → 16(모바일 18 SVG 단위). 차트 반지름 103 → 132. 8방향 선택 화살표는 외곽의 91% 안쪽에 두고 차트 경계로 clip한다.
- 공유 보고서의 최초 보관일 + 최대 7일을 기준으로 Redis 절대 만료시각을 설정한다. 조회·경쟁사 보완·재저장은 만료시각을 연장하지 않는다.
- 비교를 포함한 결과는 연결한 기준 보고서의 더 이른 만료일을 따른다. 기준 보고서가 없거나 만료되면 서버가 비교·재저장을 거부한다.
- 처음 저장한 결과의 보관 정보를 홈 화면 상태에도 전달해, 같은 화면에서 비교를 추가한 후 다시 저장해도 최초 만료일을 유지한다.
- 만료일은 한국시간으로 안내한다. 열린 결과 화면도 만료시각에 결과·다운로드 조작부를 내리고 새 진단 안내를 표시한다.
- 기존 21일 자료는 배포 빌드 마지막의 `migrate:report-retention`에서 정리한다. 7일을 지난 자료와 보관 시점을 확인할 수 없는 구형 자료는 삭제하고, 남은 자료는 원래 생성시각을 기준으로 만료를 줄인다. 실패 시 배포 빌드를 실패 처리한다.
- 보고서 본문을 로그에 남기지 않는다. 운영/미리보기 저장소를 구분한다. 기존 인증·소유권 검사를 유지한다.

## 검증

- 자동 회귀 검사 193개 통과, 타입 검사 및 전체 배포 빌드 통과.
- 실제 Redis 6.2의 Lua·TTL 연동 검사 5개 통과: 7일 만료, 경계 API 차단, 재저장·경쟁사 보완의 만료 유지, 비교 기준 승계, 기존 자료 migration, 재조회 없이 자동 삭제.
- 기존 Redis 보안 연동 검사 5개 통과: 승인·로그인·소유권·회수, 동시성, HTTP 경로, 보고서 저장.
- 실제 Chromium + 합성 결과 데이터: 320/390/768/1440px에서 가로 넘침 없음. 레이더 8방향 화살표와 라벨 경계 통과. 저장 후 비교를 추가하고 재저장하는 요청에서도 최초 보관 정보 유지. 만료 시 결과 DOM 제거 확인.
- 전체 결과 화면: HTML 텍스트 대비 검사, 200% 글자 확대 후 모바일 줄바꿈, 긴 설명 보존, 브라우저 오류 없음. 테스트 스크립트는 `tests/browser/radar-retention.cjs`, `web-stability.cjs`, `readability.cjs`.
- 서버와 클라이언트 간 지연 때문에 만료시각이 조회할 때마다 줄어들던 문제는 Redis `TIME` 기준으로 수정했다.

## 운영 확인 및 한계

- 운영 주소: https://www.mktscanner.com/
- GitHub `main` 병합 후 Vercel READY 및 `[report-retention] 7-day policy applied` 빌드 로그를 확인해야 한다.
- 로컬 브라우저 검사는 합성 보고서로 진행한다. 실제 외부 AI의 응답 품질·가용성은 이 결과로 보장하지 않는다.
- 7일은 서비스 정책이며 법정 면책 기간이 아니다. 개인정보 보호법 제21조는 보유기간 경과·목적 달성 등 불필요해진 개인정보의 지체 없는 파기와 별도 보존 의무의 예외를 정한다.
- 내려받은 PDF·복사본, 외부 AI 제공자의 데이터, 계정·문의·접근기록 및 인프라 백업은 공유 보고서 삭제와 별개이다. 외부/백업의 삭제를 확인했다고 표시하지 않는다.
