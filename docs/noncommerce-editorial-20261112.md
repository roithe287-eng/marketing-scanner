# 비커머스 결과의 업종별 실행안 확장

## 결과

- 27개 목적·전문 서비스 기준, 26개 지역 업체 분류, 16개 시즌 프로필을 공통 결과 생성기에 연결했다. 이 수는 분류 체계별 프로필 수이며 서로 배타적인 69개 업종이라는 뜻은 아니다.
- 각 업종의 제공 대상, 선택 조건, 근거 자료, 진행 방식으로 탐색·비교·이용 단계를 구분한다. 단계별 랜딩 구성은 4개 행동 지침으로 축약하고 버튼과 지표를 분리했다.
- 채널 4개, 콘텐츠 기획 6개, 이용 흐름 5개, 지표 5개, 실행 순서 4개에 서로 다른 역할을 부여했다. 정보·공공·커뮤니티에는 비용 비교·상담 접수·계약 지표를 일괄 적용하지 않는다.
- 근거가 없는 단계에 제목·설명을 본문 근거로 재사용하지 않는다. 같은 원문은 한 묶음 안에서 한 번 배정하며 출처 링크를 보존한다. 원문과 답변의 중복 노출은 출처 보기로 접었다.
- 저장된 비커머스 결과는 보관된 원문으로 실행안을 다시 구성한다. 원본 데이터, 수집 시각, 점수는 변경하지 않는다.
- 지역 업체가 기존 unknown 목적에 빠지던 분기를 보완했다. 구매 목적이 있는 페이지, 정보형·공공형 페이지의 우선 분류는 유지한다. 동물병원과 사람 병의원, 식당 프랜차이즈 지점과 가맹 모집 본부를 분리한다.
- 네이버 API 조회나 공식 공지의 범위는 확장하지 않았다. API 기본정보와 직접 확인할 운영정보의 구분을 유지한다.

## 검증

- 프로필별 스키마, 단계별 중복 지침·CTA·지표, 근거 배정, 정보형 지표 및 안전한 렌더링 검증.
- 지역 업종 12종과 시즌 16종은 모의 HTML 수집 → 업종 판별 → 결과 생성까지 통합 검사.
- 가맹 지점/본부, 병원 컨설팅/병의원, 동물병원/사람 병의원, 구매형/비커머스 및 저장 결과의 멱등성·관측 보존 검사.
- 전체 테스트, TypeScript 검사, Next.js 프로덕션 빌드 후 운영 배포 확인.

실제 모든 업체 URL을 전수 접속한 검사는 아니다. 알려지지 않은 세부 업종은 가장 가까운 분류 또는 일반 서비스 기준으로 생성한다.
