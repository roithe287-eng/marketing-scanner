# 마케팅스캐너 새 스레드 작업 검증

확인일: 2026-10-01. 시작 기준은 main `842b3a435c334f68c51cba3fd4e2c51a4546a292`이며, 작업 브랜치는 `codex/thread-handover-20261001`입니다.

## 변경 내용

- PDF는 전체 보고서 데이터의 실제 글자 너비를 측정해 페이지를 배치한 뒤 Canvas에 직접 그립니다. 페이지마다 앱 DOM을 복제하고 캡처하던 비용을 없앴습니다. 화면에서 접힌 상세도 모두 포함하며, 긴 문단·공백 없는 문자열·긴 URL은 다음 줄과 페이지로 이어집니다.
- 출처 링크는 줄별 PDF 링크 주석으로 보존합니다. 본문과 페이지 번호의 영역을 분리하고, 제목과 다음 본문이 가능하면 함께 놓이도록 했습니다.
- 보고서가 변경되면 기존 공유 URL을 초기화합니다. 이전 요청이 늦게 도착해 최신 결과의 공유 상태나 오류를 덮어쓰지 않습니다.
- 경쟁사 비교의 완료·빈 결과·미제공·실패·시간 초과 상태를 보고서에 저장합니다. 실패·시간 초과 시 원래 분석 화면에서 다시 시도할 수 있고, 공유 보고서와 PDF에도 상태가 남습니다.
- Pretendard 1.3.9를 npm 잠금 파일과 `next/font/local`로 고정해 같은 사이트에서 제공합니다. PDF는 화면의 실제 글꼴을 사용합니다. SIL OFL 라이선스 원문은 `public/fonts/Pretendard-LICENSE.txt`에 포함했습니다.

## 브라우저 및 파일 검증

시간은 브라우저의 PDF 완료 상태에 표시된 실측값으로, 같은 원격 Chrome 환경에서 확인했습니다. 입력 크기·기기·글꼴 로딩에 따라 달라질 수 있습니다.

| 입력 | 이전 구현 | 최종 구현 | 파일 검사 |
| --- | --- | --- | --- |
| 긴 한글 답변 10개, 긴 URL, 공백 없는 반복 문자열을 포함한 동일 합성 보고서 | 43페이지 / 121.9초 | 42페이지 / 4.0초 / 약 23.1MB | 출처 링크 12개, 전 페이지 좌우 범위 검사, 페이지 경계와 마지막 내용 확인 |
| 실제 `https://prorealmkt.com/` 분석의 저장된 보고서 | 별도 이전 분석 결과와 직접 비교하지 않음 | 33페이지 / 3.8초 / 약 9.1MB | 링크 주석 27개, 전 페이지 좌우 범위 검사, 전체 페이지 이미지 및 마지막 페이지 확인 |

- 최초 공유 → 보고서 요약과 경쟁사 시간 초과 상태 변경 → 이전 URL 초기화 → 다른 공유 ID 발급 → 새 서버 페이지에서 갱신된 요약과 실패 안내 유지 확인.
- GEO 결과 없는 보고서는 GEO 영역 없이 정상 표시. 구버전 보고서는 브랜드 언급 기반 측정이며 실제 URL 출처 인용률과 비교할 수 없다는 안내 유지.
- 390px iframe에서 상세 열림·닫힘 확인. 세로 스크롤바를 제외한 본문 너비와 스크롤 너비가 모두 373px으로, 긴 답변을 펼친 뒤에도 가로 넘침 없음.
- 검증 브랜치에서 실제 사이트 분석, OpenAI 응답 5건, Redis 공유 저장, 공유 페이지 새 요청, 공유 화면에서 전체 PDF 다운로드 확인.
- 리드 정보 입력창이 열리는 것까지만 확인했으며, 연락처 전송과 Slack 알림은 실행하지 않았습니다.

## 자동 검사 및 운영 반영 조건

- 자동 테스트 22개 성공. 긴 한글·공백·결합 문자·이모지의 내용 보존, 줄 너비, 페이지와 푸터 경계, 긴 출처 링크, 경쟁사 실패 상태의 공유/PDF 보존을 추가 검증했습니다.

- 병합 직전 main 변경 여부와 PR 머리 커밋을 확인합니다. 운영 배포 후 공개 공유 보고서와 PDF 다운로드, 자체 제공 글꼴, 접근 제한 안내를 확인합니다.

## 외부 서비스 검증 경계

- Gemini 5건은 HTTP 429로 측정 실패했습니다. 실패 응답을 인용률 분모에서 제외하는 기존 동작과 계정 사용량·결제 설정 확인 안내를 확인했습니다. Gemini 계정의 할당량·결제 설정은 변경하지 않았습니다.
- 미리보기에는 네이버 검색 키가 없어 실제 경쟁사 비교 성공 경로는 확인할 수 없습니다. 이 환경에서는 경쟁사 미제공 안내와 완료된 기본 보고서의 공유/PDF 다운로드를 확인했습니다. 네이버 운영 키는 변경하지 않았습니다.

운영 배포의 확인 결과는 해당 PR과 커밋 상태에 기록합니다. 다른 대화의 실행을 원격 중지하는 기능은 이 작업에 포함되지 않으며, 중지했다고 간주하지 않습니다.
