# 근거 기반 보고서 확장과 레이아웃 정비

## 품질 기준

1. 점검 기록, AI 관측, 검토 제안을 구분한다. 실제 전환율·손실액·정확도를 추가 측정한 것처럼 표시하지 않는다.
2. 호출 실패·중복 관측·출처 판정 불가·메타데이터 미수집을 0점이나 서비스 부재로 처리하지 않는다.
3. 모든 추가 항목은 저장된 근거와 연결하고, 링크는 안전한 HTTP(S)만 표시한다. 새 AI 요청·추가 수집·외부 메시지 발송이 없다.
4. 개인 분석/공유 화면이 같은 ReportLayout을 사용하며 PDF에 새 해석과 전체 상세를 보존한다.
5. 진짜마케팅의 차콜·화이트·레드를 중심으로 위계를 통일한다. Pretendard, 충분한 여백, 텍스트 상태, 키보드 포커스, 반응형 재배치를 유지한다.
6. 원래 진단·경쟁사 재시도·딥다이브·공유·PDF 동작을 유지하고 변경 범위의 위험을 테스트한다.

## 이번에 추가한 8개 기능

- 데이터 수집 현황: 페이지 체크/기술 점검/AI 출처 판정/경쟁사 상세 수집을 실제 저장 범위로 표시.
- 전환 준비도: 첫인상→신뢰→행동→전환 흐름의 기존 점수를 연결. 실제 전환율이 아님을 명시.
- 질문과 답변 페이지 지도: 확인한 자사 출처, 입력 페이지 검토 후보, 재측정 필요를 구분. 사실 입력이 필요한 콘텐츠 작성 틀 복사.
- 브랜드 답변 검토함: 정상 출처 판정에서 브랜드 언급+외부 출처+자사 출처 없음의 조합을 대조 대상으로 표시. 오답으로 자동 확정하지 않음.
- AI 출처 검토함: 유효 관측의 URL을 모으고 구분 필터, 관측 횟수, 연결 질문을 제공. 링크 현재 상태는 별도 확인.
- 경쟁사 메시지 비교 지도: 저장된 제목·메타 설명의 6개 메시지 유형과 실제 탐지 표현. 검색 결과 설명을 수집된 페이지 정보로 대신하지 않음.
- 키워드 연결 기회: 본문 빈도 상위 20개에서 제목·설명 미포함 후보 최대 8개. 검색 수요로 해석하지 않음.
- 통합 보완 목록: 7개 진단 출처와 브랜드 대조를 분야별 필터·검색·근거/실행 상세로 통합.

## 화면 구조

핵심 요약 → AI·GEO → 검색·페이지 → 경쟁사 → 실행 과제.
상단 고정 목차, 현재 장 표시, 장별 처음으로 이동, 펼침형 상세, 데이터 출처 라벨, 오류/미확인 상태를 제공한다.
기존의 ‘시니어 컨설턴트 검수’ 문구는 검수 기록이 없으므로 ‘공개 페이지 기반 자동 진단 · 실행 전 담당자 검토’로 바꾼다.

## 후속 아이디어

1. **수정 증거 타임라인**: 작업 URL·수정일·변경 항목을 저장하고 관측 변화와 나란히 표시. 인과관계는 별도 검증.
2. **정확도 검토 기록**: 담당자가 브랜드 답변의 정확/오류/보류와 근거를 기록. 이번 규칙 기반 대조와 사람의 확정을 구분.
3. **질문 의도별 콘텐츠 제작 보드**: 가격·선택 기준·비교·문제 해결 질문을 담당자/페이지 단위로 관리. 실제 작성하지 않은 항목을 완료 처리하지 않음.
4. **진단 간 불일치 검토**: 같은 H1·브랜드명·구조화 데이터에 대해 서로 다른 모듈의 판정이 엇갈리면 근거를 나란히 표시. 원문 수집 기준 통일이 먼저 필요.
5. **광고주 1페이지 브리프**: 확인한 변화·실행 과제·담당자 확인 사항만 추려 별도 인쇄. 전체 진단은 링크로 연결.

## 검증

구현 시점 자동 테스트 47/47 통과, TypeScript 검사 및 Next.js 프로덕션 빌드 통과.
실제 운영 화면의 탐색·필터·복사·PDF 검증 결과는 배포 PR에 이어 기록한다.
