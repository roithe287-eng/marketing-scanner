# 마케팅스캐너 다음 개발 계획

목표: 진단 항목을 추가하는 것보다, 측정의 근거를 확인하고 다음 행동을 결정하기 쉽게 만든다.

## 이번에 구현하는 개선

| 기능 | 해결하는 문제 | 동작과 검증 기준 |
| --- | --- | --- |
| 경쟁사 후보 선정 기록 | 검색 결과에 기관 광고문의·드라마 회차 페이지가 포함되는 오분류 | 서비스 검색어와 페이지의 역할을 함께 확인해 명확한 공공 광고 매체 문의·드라마 회차 시청 페이지를 제외. 선정·제외 근거와 웹문서 API 응답 순서를 공유/PDF에 보존 |
| 수집 미확인 구분 | 접속 실패가 H1·CTA 부재로 평가되는 문제 | 페이지 수집 실패 시 비교표는 ‘미확인’으로 표시하며 평균 분모에서 제외. 전체 미확인은 평균도 미확인 |
| GEO 우선 실행 과제 | 답변 원문 10개를 읽어야 행동을 결정할 수 있는 문제 | 현재 관측에서 최대 3개 과제를 먼저 제시. 근거·실행 내용·완료 기준·검토 페이지를 한 카드에 표시 |
| 질문 재사용 | 수정 전후의 질문 조건이 달라지는 문제 | 두 AI 엔진의 중복 질문을 하나씩 정리해 최대 5개를 복사. 복사가 안 되면 펼친 읽기 전용 입력란에서 직접 복사 |

GEO 과제는 기존 답변·출처·페이지 준비도 결과에서 계산한다. 추가 AI 호출이 없으며, 과제를 펼치는 동작도 별도 요청을 하지 않는다. 모든 관측이 실패·미확인이면 콘텐츠 부족을 단정하지 않고 관측 복구부터 안내한다. 수정 완료와 인용률 상승은 다른 결과이므로 완료 기준에 성과 보장을 넣지 않는다.

네이버 검색 응답은 30개를 검토하되 상세 페이지 수집은 최대 8개, 최종 비교는 최대 5개로 제한한다. 키워드 AI 호출은 8초·재시도 없음으로 제한하고 실패 시 기존 규칙으로 전환한다. 검색어 관련 표현은 서비스 일치의 단서이며 직접 경쟁 관계의 확정 판정은 아니다. 특정 공공기관 도메인을 일괄 차단하지 않는다.

자동 정기 측정은 이번 변경에 포함하지 않는다. 반복 API 비용과 관측 조건을 먼저 정해야 한다. SEO·GEO 개선의 효과는 동일 조건의 관측과 실제 유입을 따로 검증한다.

## 참고와 검증 범위

- 네이버 공식 웹문서 검색 API: https://developers.naver.com/docs/serviceapi/search/web/web.md . 이 API는 웹문서 검색 결과를 반환하며 ‘직접 경쟁사’ 판정 API가 아니다. display 허용 범위 내에서 30개를 요청한다.
- 기존 운영 검증: `docs/GEO_COMPETITOR_LIVE_VERIFICATION_20261001.md`.
- 새 기능의 회귀 테스트는 기관 광고문의 제외/공공 도메인 보존, 도메인 유사 문자열, 수집 예산 8개, 빈 결과, 관측 전체 실패/부분 실패, 비교표 미확인, 공유·PDF 근거 보존을 확인한다.
- 타입·빌드 검사 후 실제 브라우저에서 기존 공유 보고서, 새 분석, 질문 복사, 선정 기록, PDF 및 모바일 너비를 확인한다. 운영 접근 예외를 사용한다면 검증 후 제거한다.

## 2026-10-02 후속 구현

고정 질문의 이전·현재 비교를 구현했다. 상세 기준과 검증 기록은 `GEO_COMPARISON_20261002.md`에 정리했다. 공유 링크를 기준으로 질문을 고정해 재측정하고, 요청 조건이 확인되는 정상 관측 쌍만 비교한다. 첫 버전 보고서는 이전 조건 기록이 없어 비교 수치에서 제외하고 새 결과부터 기준으로 사용할 수 있다.

다음 구현 우선순위는 질문별 답변 페이지 지도다. 입력 페이지와 발견한 자사 링크를 제한된 예산 내에서 수집하고, 질문마다 실제 답변 문장·출처 URL·수집 시각을 연결한다. 확인하지 않은 페이지는 ‘답변 없음’으로 판정하지 않는다. 수정 제안에는 현재 확인한 답변과 보완할 질문을 함께 표시한다.
