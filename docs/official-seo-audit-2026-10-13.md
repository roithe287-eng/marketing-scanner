# 네이버·Google 공식 SEO 기준 재검증

확인일: 2026-10-13. 대상은 Search Advisor SEO 도움말과 Google SEO 기본 가이드의 좌측 메뉴에서 연결되는 고유 기준 문서다. 전역 탐색의 영상·뉴스·팟캐스트·커뮤니티 등 자료 링크는 기준 문서와 구분했다.

| 범위 | 고유 문서 | 처리 |
| --- | ---: | --- |
| 네이버 좌측 메뉴 12개 분야 | 55 | 전체 대조, 문서별 기준 반영 |
| Google 검색·크롤러·도움말 문서 | 166 | 전체 대조, 문서별 기준 반영 |
| 네이버 교육 페이지의 연결 PDF | 2 | 추가 대조, 과거 예시/현재 기준 구분 |
| 전역 탐색/자료 링크 | 10 | 메뉴 목록에 기록, 일반 사이트 합격 항목으로 만들지 않음 |

Google 도움말 3035947의 한국어 응답은 429여서 같은 문서의 영문 공식 원문으로 확인했다. `reviewedUrl`과 `reviewNote`에 기록했다. 가이드 카탈로그는 원문 전문 복제가 아닌 작성한 요약·적용 범위·속성 색인이다. 속성의 데이터 형식·허용값·대안·중첩·정책 및 실제 기능 자격 검증은 연결된 공식 명세와 검증 도구에서 진행한다.

## 기존 항목과 보강

| 분야 | 기존 범위 | 보강한 범위 |
| --- | --- | --- |
| 크롤링·메타 | 네이버 URL/robots·제목·설명 | Google 봇 지시 범위, body 메타, 2MB 수집 범위, head 위치 |
| 리소스·링크 | 링크/스크립트 개수 | 같은 출처의 리소스 robots 대조, 실제 href·JS·hash 경로·프로토콜 |
| 대표 URL | 네이버 절대 canonical | Google 상대 주소 허용, HTTP Link 충돌·fragment·head 밖 선언 |
| 이미지·모바일 | alt·viewport 관측 | 장식 alt 구분, src, 엔진별 파비콘/이미지 요건, 모바일·실사용자 지표 직접 확인 |
| 구조화 데이터 | JSON-LD 존재·일부 상품 정보 | 객체별 기본 필드 대조, 대안 속성·참조 보류, 문서별 필수/권장/조건부 색인 |
| 사이트 운영 | 선택된 네이버 문서 | 사이트맵 확장·JS/AMP·다국어·상품/피드·이전·뉴스/영상/스토리·보안·정책·실적·AI·제휴·IndexNow |
| 실행·출력 | 네이버 개선 과제 | 새 관측의 과제·버전별 비교·상세 PDF·전체 기준 검색/필터 |

네이버 기존 29개 검색/광고/쇼핑/API 항목은 보존한다. 새 공식 검색 점검은 제한된 관측과 22개 분야의 직접 확인 작업으로 구성한다. 직접 확인을 관측 통과로 바꾸거나 페이지 한 개의 결과를 사이트 전체 인증으로 확대하지 않는다. 특정 업종/국가/제휴 타입이 없는 일반 사이트에 그 타입을 필수로 요구하지 않는다.

짧지만 유효한 문서를 HTML 100자/본문 50자 조건으로 거절하던 수집기 조건도 제거했다. 비어 있는 응답과 의미 있는 콘텐츠가 전혀 없는 응답은 여전히 거절한다.

## 구현 자료

- `lib/officialSeoGuideData.json`: 221개 문서의 적용 범위·작성한 보강 기준·유형별 속성 색인.
- `tests/fixtures/official-seo-sidebar-20261013.json`: 좌측 메뉴의 고유 URL·제외한 자료 링크·교육 PDF 목록.
- `lib/officialSeoEvidence.ts`: 이미 받은 HTML에서 제한된 근거 수집. 추가 외부 요청 없음.
- `lib/analyzeOfficialSeo.ts`: 관측/보완/직접 확인 판정. API 결과에 버전과 관측 시점 저장.
- `lib/officialSeoStructuredData.ts`: 일부 명시 JSON-LD 객체의 기본 필드 확인. 서로 다른 객체의 필드를 합쳐 통과시키지 않음.
- `components/report/OfficialSeoPanel.tsx`: 보완 항목 우선, 엔진/상태 필터, 전체 기준 검색·분야 필터·20개 단위 페이지.
- `lib/officialSeoDocument.ts`: 저장된 관측·실행 순서·완료 기준·문서별 기준과 공식 링크를 상세 PDF에 연결.

관측 원문은 페이지 데이터이므로 HTML로 삽입하지 않는다. 고객 식별·집계·관리자 권한·계정/보고서 격리·법적 고지는 변경하지 않는다. 인증 없는 API와 관리자 진입 차단은 기존 회귀 검증을 유지한다.

## 확인할 회귀 위험

Googlebot-News/Yeti 지시 오적용, body noindex 누락, 상대 canonical 오판정, 외부 CDN에 원래 호스트 robots 오적용, 장식 alt 오판정, 서로 다른 스키마 객체의 필드 혼합, 대안 속성의 동시 강제, 네이버 제휴 영상의 일반 사이트 강제, 구버전 보고서의 가짜 재관측, 보고서 저장/PDF의 누락·카드 넘침을 테스트한다.
