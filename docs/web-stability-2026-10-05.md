# 웹 진단 안정성 개선 — 2026-10-05

앱 신규 개발은 보류하고 기존 웹사이트의 진단 요청과 결과 표시를 보강했다.

## 변경 이유와 동작

- AI 스키마 검증 실패 결과가 강제 형변환으로 화면에 전달되던 경로를 제거했다. 완전한 JSON과 필수 진단 필드가 검증된 결과만 제공한다. 기존 상세 설명의 출력 길이는 줄이지 않았다.
- 페이지 수집, AI, 경쟁사, Redis 요청에 취소 신호와 처리 시간 상한을 적용했다. 메인/경쟁사 분석은 요청 시작 후 최대 48초, 상세 분석은 34초의 작업 예산을 사용하며, 함수 제한 안에 사용량 처리와 실패 응답을 마칠 여유를 둔다. 수집은 14초, Redis 명령은 5초로 제한한다. 이는 응답 속도 보장이 아니다.
- 필수 진단이 유효하면 부가 분석의 오류·미수집·시간 초과를 별도 안내하고 완료된 결과를 제공한다. 없는 데이터에 점수를 채우지 않는다.
- 재진단이 실패하면 이전의 유효한 결과를 유지한다. 연속 제출과 이전 경쟁사 응답의 덮어쓰기를 차단하고, 화면 이탈·상세 창 닫기 시 진행 요청을 취소한다.
- 접근 상태와 경쟁사 상세 응답을 검증한다. 접근 응답이 비정상이면 이용 가능 상태로 처리하지 않는다.
- 공유 저장과 이전 보고서 불러오기에 응답 본문까지 포함하는 시간 제한을 적용했다. 저장 실패 사유를 안내하고 현재 결과로 재시도할 수 있다.
- Redis의 자동 재시도는 비멱등 명령의 중복 실행을 피하도록 중단했다. 명시적인 사용량 예약/완료 Lua와 소유자 확인은 유지한다.

## 검증

- `npm test`: 154개 통과. 요청 격리, 외부 취소, 부가 분석 실패, OpenAI/Redis 취소 전파, 잘못된 AI 출력, 잘린 JSON, HTML 502/504, 응답 본문 지연을 포함한다.
- `npm run build`: 통과. 최종 API 시간 배분 변경 후 Next 운영 빌드도 재확인했다.
- `tests/browser/web-stability.cjs`: 로컬 운영 빌드에 브라우저 응답 fixture를 제공해 연속 제출, 결과 유지, 이전 요청 취소, 공유 저장 재시도, 경쟁사 상세 오류, 접근 응답 실패를 확인했다. 320/390/768/1440px에서 가로 넘침 및 미처리 브라우저 오류 없음.
- 로컬 브라우저 검증 실행: `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/path/to/chromium node tests/browser/web-stability.cjs`. Playwright가 필요하며 `CODEX_PRIMARY_RUNTIME_NODE_MODULES`가 있으면 해당 설치를 사용한다.

## 검증 범위와 잔여 한계

브라우저의 허용 상태와 분석 결과 fixture는 로컬 테스트에서만 사용한다. 운영 승인 계정이 제공되지 않았으므로 실제 고객 계정에서 외부 AI·검색 API·보고서 저장까지 연결한 종단 검증을 완료했다고 주장하지 않는다. IP 예외, 계정 승인, 보고서 소유자 보호 및 SSRF 방어를 해제하지 않았다.

외부 서비스의 장애, 공급자 한도, 저장소 전체 중단은 여전히 오류로 안내될 수 있다. 완전한 네트워크 단절 후 서버 작업이 반드시 취소되는 것은 호스팅 환경의 연결 중단 전달에 달려 있으므로 서버 자체 시간 상한도 함께 적용했다. Redis 장애 중 사용량 정산의 완전한 복구나 영구 작업 큐를 구현한 변경은 아니다.
