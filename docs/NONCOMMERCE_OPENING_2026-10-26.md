# 비커머스 보고서의 시작 화면 · 2026-10-26

## 문제와 새 읽기 순서

사용자가 감자유학 보고서 화면을 제시하며 목적별 미확인 카드와 측정 한계가 먼저 반복돼 사이트가 제대로 준비되지 않은 것처럼 보인다고 지적했습니다. 비커머스는 제시한 대안 중 고객 질문·콘텐츠 개선안을 먼저 보여주는 방식을 적용합니다.

서비스·기업·교육·정보·공공 목적이 저장된 보고서는 대표 주제와 다음 행동을 보여주는 요약으로 시작합니다. HTML 충족 숫자 대신 목적에 맞춘 분석 방향을 표시하고, 첫 챕터에 대표 키워드 → 추천 고객 질문 → 답변 초안·콘텐츠 보강 방향을 배치합니다. 기존 AI·GEO 챕터에서 같은 콘텐츠를 중복 표시하지 않습니다.

목적별 상세 카드, HTML 관측·측정 범위, 원문 재확인과 부가 분석의 응답 상태는 검색·페이지 챕터의 접힌 상세 영역에서 확인합니다. 실행 우선순위는 실행 과제로, 보관 안내는 보고서 뒤로 옮깁니다. 기본·제한 가이드의 생성 방식과 범위는 내용을 삭제하지 않고 펼쳐 확인하도록 보존합니다. 키워드 분석이 없는 저장 보고서에는 실제 분석을 완료했다고 가장하지 않고 콘텐츠 기획의 시작점을 안내합니다.

한 장 요약 PDF도 주요 주제·다음 행동, 고객 질문, 콘텐츠 보강 방향으로 시작합니다. 전체 PDF에서는 콘텐츠 질문·초안을 목적별 상세 점검보다 먼저 배치하고 HTML 관측값·산식·원문은 상세에 그대로 남깁니다.

이 변경은 읽기 순서와 표현을 조정합니다. 측정하지 않은 화면·전환에 점수나 레이더 면적을 만들지 않으며, 원문 미확인을 실패나 통과로 바꾸지 않습니다. 판매·혼합·미확인 및 목적 필드 없는 구버전 보고서의 기존 시작 구조는 유지합니다. 새 목적 필드가 있는 보관 결과도 화면 새로고침과 PDF 재생성에서 새 구성을 사용합니다. 분석 데이터·캐시·점수 산식·권한·보관 기간은 변경하지 않습니다.

## 검증

- 단위 366개, 격리 Redis 통합 54개, 타입 검사와 포켓 포함 운영 빌드 통과.
- 서비스·기업·교육·정보·공공·예약 6개 목적의 첫 콘텐츠, 닫힌 상세 근거, 문서 링크·ID, 원본 불변, 구버전·혼합·미확인 호환을 검사합니다.
- 기본·제한 가이드의 실제 수집 범위를 유지하며, 요약 PDF에는 미측정을 0점으로 바꾼 성과 점수를 넣지 않습니다. 상세 PDF에 기존 HTML 관측값·고유 문구·출처가 보존되는지도 확인합니다.
- 실제 운영 PDF 렌더 함수와 Pretendard를 사용해 서비스·교육형 한 장 요약을 생성하고 Poppler 이미지로 육안 검수했습니다. 두 결과 모두 1페이지이며 한글·줄바꿈·여백·카드 경계가 정상입니다. 이 샘플은 합성 원문으로 만든 검수용 결과이며 실제 업체의 측정 자료가 아닙니다.

배포는 검사한 Git tree와 업로드 tree의 일치를 확인하고, Vercel 작업 브랜치 빌드 성공 후 main에 병합하는 기존 흐름을 사용합니다. 운영 화면의 확인은 별도로 수행합니다.
