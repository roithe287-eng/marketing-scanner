# 전체 화면 정렬·그래픽 개선 검증

## 범위와 기준

URL 입력·미리보기, 5개 보고서 장, 접힌 상세 패널, 네이버 4개 분야, 공유 보고서, 한 장 요약·전체 PDF를 점검했습니다.

- 공통 바깥 여백 28px, 모바일 20px/좁은 화면 16px. 안쪽 근거 박스는 18px/16px.
- 제목·배지·펼침 기호는 전용 열에 배치하고 모바일에서는 근거·상태를 순서대로 재배치.
- 한국어 어절을 우선 보존하되 긴 URL과 공백 없는 문자열은 박스 안에서 줄바꿈.
- 기존 8방향 레이더와 원본 점수 유지. 실제 데이터가 없는 곳에 그래프나 판정값을 만들지 않음.
- 보완 목록의 분야별 막대는 과제 개수이며 중요도나 성과 점수가 아님.
- 본문은 줄임표 없이 유지. TO-BE 카드는 긴 상세를 열어도 옆 카드를 불필요하게 늘리지 않음.
- 색상뿐 아니라 명칭·기호·개수로 상태 전달. 애니메이션 감소 설정을 존중.

## 변경

1. 입력 폼·미리보기·결과·상세·법적 안내까지 글자 크기, 행간, 카드 간격 조정.
2. GEO 현재/진단/개선, 핵심 이슈, 체크리스트에 공통 근거 흐름 컴포넌트 적용.
3. 체크리스트 상태 분포, 일정 카드, AS-IS/TO-BE 비교, 퀵윈 실행 순서 재구성.
4. 통합 과제 필터에 저장된 분야별 개수와 비중을 표시.
5. 네이버 제목·근거·배지·문서 목록 정렬 개선. TO-BE에도 직접 선택하는 복사 대안 제공.
6. 좁은 화면에서 광고비 수치 박스가 설명을 밀어내지 않도록 분리. 임의 가중치 기반임을 문구에 명시.
7. 경쟁사 상세 모달의 키보드 포커스 순환·복귀 및 작은 화면 높이·닫기 버튼 개선.
8. PDF 네이버 분야별 지도 추가. 기존 보고서는 기준 개수와 재진단 안내만 표시.
9. PDF 레이더 라벨 중앙 정렬, 긴 GEO 준비도 제목과 점수 사이 간격 보완.

## 확인한 증거

- 전체 자동 회귀 검사 83개 통과. 긴 문장, 원문 보존, 안전한 텍스트 출력, 개수 합계, PDF 텍스트 영역 충돌·페이지 경계 포함.
- 프로덕션 빌드 통과.
- 실제 Pretendard로 25쪽 검증 PDF를 생성하고 한 장 요약, 네이버 시각 지도, 상세 가이드, 마지막 이용 안내 페이지를 렌더링하여 확인.
- 외부 계정/API 상태를 이번 스타일 변경의 성공 근거로 사용하지 않음.

## 검증 경계

신규 분석 입력은 운영 접근 정책 때문에 클라우드 점검 브라우저에서 실행할 수 없습니다. 공개 공유 보고서를 이용한 화면 점검과 로컬의 입력·데이터·PDF 회귀 검사를 구분합니다. 계정 실측이나 실제 휴대폰 검증으로 표현하지 않습니다.
