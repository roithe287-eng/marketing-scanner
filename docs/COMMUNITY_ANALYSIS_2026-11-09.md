# 커뮤니티·포털 분석 보완 (2026-11-09)

아이보스 공개 메인 HTML에서 기존 목적 분류는 교육·프로그램형, 주요 행동은 달력 링크의 시험 접수 일자로 나왔다. 게시글 제목·입점업체 소개와 사이트 자체 정보를 같은 후보에 넣고, 회원가입 같은 헤더 행동을 제외하던 결과다.

사이트 소개와 독립적인 게시판·게시글·회원 참여 구조를 함께 확인해 커뮤니티를 식별한다. 특정 도메인 허용 목록은 사용하지 않는다. 커뮤니티는 기존 content 유형의 선택적 community 자료로 보관하므로 이전 보고서와 호환된다. 실제 교육 상세·상품 상세와 커뮤니티를 설명하는 일반 칼럼은 분리한다.

- 게시판 탐색, 회원가입, 글·질문·댓글 참여, 구독과 교육·광고·대행 의뢰의 별도 전환을 점검한다.
- 게시글·입점업체의 의료·상품·가격 문구가 업종·상품군·CTA·고객 질문에 섞이지 않도록 메인 진단, AI 검색 준비도, 질문 추천, 키워드와 경쟁사 입력에 같은 범위를 적용한다.
- 메인에서 발견한 동일 사이트 공개 게시판 2개와 글 상세 1개를 최대 5.5초 내 표본 수집한다. robots 규칙을 확인하며 로그인·쓰기·변경 작업·외부 호스트·비허용 쿼리 및 해당 경로로의 리다이렉트는 수집하지 않는다.
- 공개 표본별 URL·제목·작성자/날짜/댓글 신호와 구조화 유형을 분리해 표시한다. 보조 문서의 H1·메타·CTA를 메인 점수에 합산하지 않는다. 수집 실패는 미확인으로 보존한다.
- 회원 수·가입률·활동률·재방문율 및 로그인 후 동작은 실측 결과로 표현하지 않는다.
- 화면과 PDF에 같은 커뮤니티 목적·체크·표본 링크가 표시된다.

## 검증

- 504개 자동 검사 통과. 새 커뮤니티 회귀 검사 7개 포함.
- 실제 수집한 아이보스 메인, 질문답변 목록, 커뮤니티 목록, 공개 글 상세 HTML을 추출기에 통과시켜 분류·링크·표본 구조를 확인했다.
- 변경 후 분류: 커뮤니티·정보 포털형. 다음 행동: 게시글 탐색·회원 참여. 마케팅 커뮤니티·마케팅 정보·마케팅 질문답변 주제 생성.
- 로컬 Node 직접 외부 요청은 환경 DNS 제한으로 실패하여 공개 HTML 원문을 별도 HTTP 수집 후 동일 추출기로 검증했다. 실제 운영 분석 검증은 배포 후 진행한다.
