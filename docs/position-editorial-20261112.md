# 결과 카드의 반복 안내와 수정 제안 개선

- 동일한 제목·메타 설명 원문 및 공통 해석 기준은 업체별 한 번만 표시한다.
- 기존 21개 업종 분류마다 비용·범위·근거·절차의 네 관점을 별도 질문, 확인 과제, 제목·메타 설명 작성안으로 구성한다.
- 범양해운과 같이 업체명만 있는 원문도 신뢰 근거(담당 거점·보상 기준)와 이용 절차(상담부터 현지 인도)를 구분해 안내한다. 작성안은 대괄호를 실제 확인한 값으로 대체해야 하는 편집 틀이다. 업체의 사실로 확정하지 않는다.
- 관점명, 탐지한 표현, 수정안에서 교체할 부분에 굵기와 밑줄을 적용한다. 탐지 규칙은 기본 접힘으로 유지한다.
- 원문 수집 실패·누락은 판정 보류를 유지한다. 미제공·예정 표현만 있는 항목에는 긍정적인 수정안을 만들지 않는다. 좌표·버블 계산은 변경하지 않는다.
- 공유 화면 및 복사 지시서, HTML·PDF 문서에 같은 관점과 수정안을 전달한다. HTML·PDF는 강조 위치도 전달하며 원문은 변경하지 않는다.

검증: 전체 627개 테스트, TypeScript, Next.js 운영 빌드 통과. 실제 컴포넌트를 사용하는 검수 페이지에서 데스크톱 및 390px·320px 화면의 밑줄·줄바꿈·가로 넘침, 접힘 동작과 업종/상태 변경을 확인했다. 21개 업종의 관점별 차이, 원문 보존, 미제공·수집 실패의 제안 보류, HTML 이스케이프와 PDF 줄바꿈·페이지 넘김 강조를 회귀 테스트한다. 인증된 운영 보고서의 실제 재분석 호출은 이번 표현 개선 검증 범위에 포함하지 않았다.
