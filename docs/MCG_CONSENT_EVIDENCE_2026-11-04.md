# MCG 진단 원문의 개인정보 동의문 분리

병원 대상 업체의 분류와 아임웹 메뉴 상태 수집을 교정한 기존 `medical_consulting` 구현을 유지하면서, 실제 결과에서 발견한 개인정보 동의문 오선택을 보완했습니다.

- 공식 메인·개원·SNS·의료서비스교육·문의 페이지를 조사하고, 현재 공개 메인 HTML을 같은 추출 함수로 재현했습니다. 병원 대상 컨설팅·마케팅·교육 업체의 목적·질문·상담 행동과 실제 의료기관의 진료 목적을 구분합니다.
- 임베디드 동의문에 포함된 회원 관리·배송·결제 문구를 서비스 본문·답변 근거에서 제외합니다. 폼 존재·병원명 등 필드 라벨·상담 링크·기술 관측은 보존합니다. 입력값·숨김 값·비밀번호는 수집하지 않습니다.
- 기존 저장 원문은 그대로 열람할 수 있으나 서비스 카드와 답변 근거로 동의문을 선택하지 않습니다. PC·모바일의 공백 차이로 반복된 서비스 문구는 대표 카드에서 한 번 선택합니다. 짧은 컨설팅·교육 서비스명은 본문 구역에서 수집하며 실제 메뉴·숨김 영역은 계속 제외합니다.
- 기존 보고서 화면·업종 카드·최상단 레이더·접근 정책·보관 기간은 유지합니다. 기존 저장 보고서의 목적·점수를 소급 재분류하지 않습니다. 진단 버전은 `v19-provider-consent-evidence`, GEO 캐시는 `geo-v3.6-provider-consent-evidence`입니다.

검증은 전체 회귀 검사, TypeScript와 운영 빌드, 실제 공개 HTML 재생을 포함합니다. 로컬 검증과 실제 운영 배포·새 진단 확인을 구분합니다. HTML 문구 관측은 실제 상담 완료·가격·광고 성과·의료 자격·적법성을 확인한 결과가 아닙니다.
