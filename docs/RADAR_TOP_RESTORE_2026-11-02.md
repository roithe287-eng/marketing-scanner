# 결과 최상단 레이더 복원 · 2026-11-02

원인: ScoreRadar가 evidenceReview가 있는 새 보고서에서 차트 대신 EvidenceReviewPanel을 반환했다. 레이더가 핵심요약 하단에도 있어 결과를 열었을 때 바로 보이지 않았다.

- 결과 영역의 첫 블록을 레이더로 배치했다. 보고서 제목·요약, 목차, 기존 홈페이지 내용·질문·답변은 그다음 순서를 유지한다.
- 근거 검토 유무와 관계없이 저장된 diagnosis의 8개 AI 참고 점수를 그린다. HTML 항목 충족률을 레이더 점수로 대체하거나 미측정 항목을 0점으로 바꾸지 않는다.
- 제목·설명·SVG 대체 텍스트·중앙 평균에 AI 참고 평가임을 표시한다. 실제 전환율·모바일 동작의 측정 결과와 구분한다.
- 최상단에는 차트, 선택한 영역 안내, 8개 선택 카드를 표시한다. 긴 우선 작업 목록은 기존 실행 영역에서 확인한다.
- HTML 근거와 미측정 설명은 핵심요약의 영역별 근거에 그대로 보존한다. 레이더를 중복 표시하지 않는다. 기존 #report-top 링크는 최상단 레이더로 연결된다.
- 새 스키마·분석 호출·점수 재계산 없이 기존 보관 결과에도 적용된다. 스토어 제한 분석과 만료된 결과의 정책은 유지한다.

검증: 근거 검토가 있는 보고서에서도 차트가 표시되는지, 8개 점수와 평균이 원래 AI 값과 같은지, 최상단 순서·중복 방지·근거 원문·접근성 표기를 검사한다. 미리보기 전용 radar-review 샘플은 외부 요청 없는 가상 자료다.
