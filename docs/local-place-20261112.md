# 네이버 플레이스 업종 확장 · 2026-11-12

## 동작

URL 분석에서 공개 HTML의 업체명·제목·H1·자사 구조화 데이터·메타 설명을 근거로 26개 업종군(기타 방문업 포함)을 판별한다. 법률·전문사무소, 식당·카페, 프랜차이즈 지점, 여행·숙박, 동물병원·펫매장·미용/위탁, 뷰티·교육·스포츠·차량·생활·소매·문화·복지·약국·금융지점을 포함한다. 이 목록은 네이버의 공식 전체 카테고리 목록을 복제한 것이 아니라 진단용 업종군이다. 미분류라도 명시적 플레이스 링크·LocalBusiness 또는 주소와 방문 안내가 있으면 공통 진단을 적용한다.

프랜차이즈 여부는 실제 업종을 유지하는 보조 정보다. 본사 페이지의 API 결과를 단일 매장이나 전체 지점 목록으로 확정하지 않는다. 업체명만 같은 후보는 일치 판정을 하지 않고 이름+주소 또는 이름+홈페이지 도메인을 대조한다. 법률·의료·수의 등 자격과 인허가 유무는 이 진단으로 검증하지 않는다.

## 수집과 보관

기존 인증·사용량 제한·보고서 보관 경로 안에서 실행한다. 새 공개 API 엔드포인트나 추가 권한은 없다. 기존 NAVER_CLIENT_ID와 NAVER_CLIENT_SECRET으로 고정된 지역 검색 API만 호출한다. 동시에 최대 2개 검색어, 각 5개, 최대 4.5초, 중복 제거 후 5개를 저장한다. 본문 수집과 병렬 실행한다. API 실패·미설정·빈 표본은 각각 표시하고 전체 진단은 계속한다.

API 응답으로 업체명·카테고리·주소·소개·업체 링크를 표시한다. 전화번호, 리뷰·저장수, 사진, 영업시간, 관리자 키워드, AI 브리핑 실제 노출은 조회값으로 만들지 않는다. 순서는 일반검색 순위가 아니다. API 소개문은 AI 모델 입력에 추가하지 않는다. 링크를 따라가 플레이스를 수집하지 않는다.

홈페이지에서 상품/서비스, 시간, 비용, 방문, 예약, 조건 6개 항목의 문구를 관측하고 원문을 연결한다. 서비스 표현을 실제 제공 여부·등록 적합성과 구분한다. 키워드 직접 입력은 화면 내 대조만 수행하며 저장/PDF에 포함하지 않는다. 기존 병의원의 4분류·30개 및 비교 기능을 유지한다.
