# 결과 카드의 역할·비교 구분 · 2026-10-26

원문, 위치 안내, 진단 설명, 수정안이 비슷한 파란 글씨와 박스로 표시되어 읽기 어려운 문제를 개선합니다. 신규·보관 결과가 공유하는 보고서 구성에 적용합니다.

- 현재·수집 원문: 회색 문서 아이콘, 검토·주의: 주황색 검색 아이콘, 수정 제안: 청록색 편집 아이콘, 근거·확인 절차: 보라색 체크리스트 아이콘, 위치: 파란색 위치 아이콘으로 구분합니다. 색뿐 아니라 항상 읽을 수 있는 라벨과 도형을 함께 제공합니다. 실패·통과 판정 색상과 별개인 읽기 역할입니다.
- 실제 원문과 제안이 있는 카피, 페이지 편집, 진단, 실행 가이드의 필드는 AS-IS / TO-BE · 제안으로 비교합니다. 원문 카드에는 없는 수정안을 만들지 않고 원문 / 위치 / 확인 방법을 구분합니다. 이전·현재 측정은 역사 비교로 남기고 TO-BE로 바꾸지 않습니다.
- URL 편집 안내, 원문 목록, 필드별 편집, 진단 체크리스트, GEO 준비도·답변·실행, 네이버·공식 SEO 검증, 페이지 목적, 근거 검토, 카피·빠른 개선, 키워드 수정, 실행 보드와 성장 계획에 공통 구성요소를 사용합니다.
- 문장 전체, URL, 수치, 측정 제한, 복사할 작업 지시서와 초안을 유지합니다. 추가 분석·네트워크 호출·데이터 변경·권한 변경은 없습니다. 비교할 원문이 없으면 미확인을 명시합니다.
- 상세 PDF에도 알려진 필드 라벨에 한해 같은 팔레트와 경계선을 적용합니다. 긴 문장과 페이지 분할, 원문 sourceId, 공통 안내 링크를 유지합니다. 반복 표현의 이유는 ‘확인 근거’로 표시합니다.
- 작은 화면에서는 원문/위치 및 전후 비교가 세로로 정렬됩니다. 긴 URL, 한글 문단, 상세 펼치기와 키보드 초점 표시를 유지합니다.

검증 기준: 실제 본문·라벨 명암 대비 4.5:1 이상, 아이콘 대비 3:1 이상, 원문·제안·완료 조건의 전체 보존, 근거 없는 TO-BE 없음, 흑백에서도 라벨로 구별, 320px 및 390px에서 가로 넘침 없음. 자동검사 373개와 TypeScript 검사를 통과했습니다. 미리보기 화면 검수 후 운영 배포합니다.
