# 업종·원문 근거 혼동 방지 검증 — 2026-11-12

입력 URL의 자사 제공 업무를 기준으로 분류하고, 고객사·관련 글·다른 지점의 내용을 자사 사실로 인용하는 경로를 보완했다.

## 변경 내용

- 제목·H1·자사 소개에서 제공 역할을 먼저 판별한다. 여행사 고객이 있는 광고대행사, 물류 SaaS, 치과 장비 제조사, 병원 인테리어 업체를 고객 업종으로 분류하지 않는다.
- 소프트웨어 저작권을 다루는 법률사무소, 미용학원, 반려견 동반 숙소와 반려견 위탁 호텔을 구분한다.
- 식당의 단독 결제 버튼은 예약·포장 결제 맥락으로 처리한다. 실제 상품·장바구니 근거가 있는 교재 및 인테리어 쇼핑몰은 커머스로 유지한다.
- 관련 Article/Course 구조화 데이터는 해당 URL·쿼리와 현재 페이지를 대조한다. 원래 수집한 구조화 데이터는 SEO 점검용으로 보존한다.
- 고객사 사례·후기·관련 글을 업종 및 자사 사실의 근거에서 제외한다. 다른 지점으로 확인된 문서는 해당 지점의 가격·운영 안내로 인용하지 않는다. 공개 수집 원문 자체를 삭제하지 않는다.
- 질문·수정 제안·AI 분석 입력·플레이스 정보에도 같은 구분을 적용한다. 고객사 전용 메타 설명과 주소·가격·운영시간이 자사 정보로 섞이지 않게 한다.
- 네이버 지역 검색 API 후보가 이름·주소는 같아도 업종이 명확히 다르면 일치 업체로 확정하지 않는다. API 원본 필드는 바꾸지 않는다.
- AI 업종 분류는 사용할 수 있는 원문의 직접 인용을 요구한다. 인용이 없거나 원문에 없는 경우 기타로 처리한다.

## 해석 범위

자동 테스트의 업종 혼동 사례는 합성 HTML이다. 실제 사이트 10개 원문 재실행과 구분한다. 테스트는 알려진 혼동 경로의 방지를 확인하며, 모든 업종·모든 URL의 정확도를 보장하는 지표가 아니다. 접근 제한·동적 화면·이미지만 있는 설명과 새 업종은 추가 수집 또는 근거 확인이 필요할 수 있다. 기존 저장 보고서의 관측값·수집 시각은 재작성하지 않는다. 최신 수집과 분류는 새 URL 분석으로 확인한다.

기존 후기 테스트는 수집 원문·링크의 보존을 유지하면서, 후기를 자사 답변 사실로 인용하지 않는 동작으로 변경했다.
