# 지역·시즌 플레이스 진단 확장 (2026-11-12)

기존 26개 업종군에 16개 계절 서비스 프로필을 겹쳐 적용한다. 스키·보드 렌탈/강습, 눈썰매/스케이트/겨울낚시, 수상레저, 서핑/다이빙, 물놀이 대여, 캠핑/피크닉, 딸기체험, 작물 수확체험, 꽃/단풍, 선상낚시/갯벌, 연말/크리스마스, 졸업/입학, 냉방 서비스, 겨울 차량, 계절 관광상품, 제철 음식이다. 계절 라벨은 콘텐츠 준비 주제이며 실제 영업 중·수요량·개장일 판정이 아니다.

## 근거와 지역

자사 제목·업체명·메타 설명·서비스 제목에서 확인한 업종만 연결한다. 해당 업종에 맞는 서비스 표현과 제한된 공개 HTML 문구를 보관한다. 후기·폼·숨긴 내용·부정된 서비스 표현을 제안 근거로 사용하지 않는다. 숙소의 '스키장 인근' 문구만으로 렌탈업체로 바꾸지 않는다.

하이원, 무주, 에덴밸리(에덴벨리), 용평, 휘닉스평창, 비발디파크, 엘리시안강촌, 알펜시아, 웰리힐리, 곤지암, 지산, 오크밸리 12곳은 홈페이지에 직접 나타난 표현을 정규화하는 목적지 사전이다. 공식 지역 출처는 seasonalPlaceCatalog.ts 각 항목에 보관한다. 리조트 위치로 업체 주소를 덮어쓰거나 평창 주소만으로 모든 평창 리조트를 연결하지 않는다. 지산은 스키 맥락으로 한정한다.

지역·실제 서비스 표현을 묶은 최대 12개 콘텐츠 제안을 생성한다. 검색량·일반검색 순위·네이버 등록 키워드를 측정한 결과가 아니다. 조회 API는 여전히 동일 업체 식별용 상호 중심 최대 2개 요청이다. 주소가 없고 홈페이지에 스키 목적지가 명시된 경우만 해당 목적지로 보조한다. 모든 지역×서비스 조합을 API에 요청하지 않는다.

## 시즌과 실행

관측한 25/26·2026/27 등 연도를 보존한다. 이전 시즌 표기는 원문 확인 대상으로 표시하며 새 시즌으로 바꿔 쓰지 않는다. 이전 연도는 현재 콘텐츠 제안에 사용하지 않는다. 개장 날짜의 '2026-12-01'을 '2026/12 시즌'으로 오인하지 않는다. 현재 시점 비교는 보고서 조회 시각의 KST 기준이다.

시즌기간, 운영/마감시간, 기간별 요금, 포함/별도 구성, 픽업/수령/반납, 사이즈/정원/수량, 기상/변경/환불의 7개 관측과 실행 안내를 연결한다. 상품별 네 가지 우선 정보·두 고객 질문·사진 방향, 예약 오픈 전/운영 중/종료 후 점검을 화면과 PDF/HTML/텍스트에 동일하게 포함한다.
