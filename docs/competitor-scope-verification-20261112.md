# 업종·경쟁사 원문 검증 — 2026-11-12

## 확인한 문제

기존 후보 선정은 제목·설명·H1의 검색어 포함 여부를 확인했지만 자사와 후보의 제공 역할을 충분히 대조하지 않았다. 재현 검사에서 병원 예약 소프트웨어가 병원 비교에, 미용학원이 미용실 비교에, 하이원 렌탈이 무주 스키 비교에 통과했다. 경쟁사 검색용 본문은 고객사 사례·관련 글을 다시 포함할 수 있었다.

## 변경

- 본 분석의 페이지 목적·업종별 구성과 동일한 기준으로 경쟁사 비교 범위를 전달한다. 후보도 실제 수집한 홈페이지의 제목·설명·H1·본문·방문 정보에서 같은 기준을 계산한다.
- 제공 업무와 상품 판매/서비스/교육/콘텐츠 유형, 확인된 세부 분야, 지역과 스키 목적지를 대조한다. 명확한 지역 근거가 있는 지역 업체는 후보의 운영 지역도 확인한다. 전국·온라인 제공이 원문으로 명시된 경우를 구분한다.
- 광고대행·소프트웨어·제조·물류 업체의 검색어에 실제 역할이 남도록 검증한다. 고객 업종, 운송하는 화물 품목, 반복 슬로건을 시장 키워드로 사용하는 경로를 차단한다.
- 고객사·관련 글·다른 지점·외부 사이트·검색 요약이 자사 키워드 원문으로 재유입되지 않도록 처리한다. 원래 수집한 메타 정보는 원문 비교용으로 보존한다.
- 제목에 상품명이 없더라도 자사 본문의 제공 내용에서 확인되면 후보가 될 수 있다. 검색 요약만으로는 통과하지 않는다.
- 후보가 이동한 최종 URL에서 자사·플랫폼·기사·중복 도메인을 다시 확인한다. 같은 도메인의 여러 검색 응답 중 관련성이 높은 페이지를 먼저 수집한다.
- 검색 결과의 명확히 다른 역할은 수집 우선순위를 낮추고, 최종 확정은 홈페이지 원문으로만 한다. 최대 8개 후보 수집 한도는 유지한다.
- 정보·콘텐츠끼리의 실제 비교는 유지한다. 상품·서비스 업체 비교의 기사 제외 규칙을 무조건 적용하지 않는다.
- 저장 보고서도 남아 있는 원문으로 명확한 업종 충돌을 걸러낸다. 후보를 제거했을 때 기존 전체 비교·포지셔닝 문구도 화면에서 제외한다. 저장 원본은 변경하지 않는다.
- 화면과 문서에 실제 비교 기준을 표시한다. 후보가 부족하면 부적합 업체로 채우지 않는다.
- 상품 판매를 명시한 인테리어 쇼핑몰이 구매 버튼 수집 여부 때문에 시공업으로 읽히던 경로도 보완했다.
- 규칙으로 고른 물류 검색어를 AI 결과라고 표기하던 출처 표시를 수정했다.

## 검증 범위

자동 테스트 877개 통과: 새 경쟁사 경계 테스트 44개와 쇼핑몰 분류 회귀 테스트 1개를 포함한다. 같은 업무의 정상 후보, 기사 비교, 본문 기반 후보, 검색어 선택부터 후보 수집까지의 모의 API 통합, 결과 직렬화, 저장 보고서의 불변성을 확인했다. TypeScript 및 Next.js 프로덕션 빌드도 검증한다.

기존 수집 원문 10개를 재실행해 비교 범위를 확인했다. 메타한방병원은 병의원·한방·부산, 무주스키월드는 스키 대여·무주, 범양해운은 해외이사·국제물류, 율촌은 법률·변호사, 트립호주는 여행으로 이어진다. 나노레시피·놀로는 보유한 홈페이지 원문만으로 상품군을 확정하지 못하면 슬로건으로 경쟁사를 찾지 않고 실제 상품 보완 경로를 사용한다. 이 재실행은 새로운 네이버 API 실호출이나 모든 사이트의 실시간 검증을 뜻하지 않는다.

새 테스트는 합성 HTML 및 모의 검색 응답이다. 실제 업계의 모든 경쟁 관계·서비스 영역을 전수 검증한 것은 아니다. 원문 수집이 제한되면 비교를 보류한다. 기존 저장 결과의 최신 검색은 URL 재분석으로 수행한다.

공식 근거: 네이버 웹문서 검색 API는 웹문서 제목·URL·요약을 반환하므로 검색 응답 자체를 업체의 제공 업무 근거로 확정하지 않는다.

## 운영 재분석과 후속 보정

PR 164 배포 후 운영 화면에서 두 URL을 새로 분석했다. meta-hbh.com은 병의원·한방·부산 기준으로 5개 후보, mujuskiworld.com은 무주 스키 렌탈 기준으로 2개 후보를 확보했다. 병원 결과에는 의료진 이름, 입원 절차, 비급여 항목, 진료시간 및 네이버 지역 검색 API의 동일 업체 조회가 표시됐다.

추가로 확인한 오류는 경쟁사 선정 기준과 도표 설명의 업종이 별도로 선택되던 점이다. 스키 렌탈의 후보는 맞았지만 스포츠·피트니스용 회원권·락커 안내가 붙었다. 이제 원문 기반 비교 범위가 도표의 업종 기준에도 우선 적용되며, 스키와 일반 대여의 제목·설명 수정안은 별도로 제공한다. 다른 URL의 비교 범위는 재사용하지 않는다.

시즌업체 질문을 목록 순서로 연결하면서 비용 질문에 픽업 안내가 붙던 경로도 수정했다. 비용·절차 등 질문 의도에 맞는 원문을 연결하고, 편집 카드의 질문은 해당 카드의 필드와 일치시킨다. 지역명이 같은 스키 목적지로 확인되면 도·시 주소가 없는 후보를 무조건 제외하지 않되, 확인된 주소가 충돌하면 제외한다. 일반 지역명만으로는 대여업 경쟁사 검색어를 만들지 않는다.

후속 회귀 테스트 14개를 추가해 총 891개 통과, TypeScript 검사 통과. 원문이 없는 항목을 제공 사실로 채우지 않으며, 검색 응답 시점과 수집 가능 범위에 따라 후보 수는 달라질 수 있다.

최종 운영 재조회에서 무주 후보의 지역 근거가 보완되면서 관광 포털에 등록된 업체 상세페이지가 통과하는 경로를 추가로 발견했다. 관광·병원·음식점 안내 플랫폼 6개 도메인과 하위 도메인은 서비스 업체 비교에서 제외한다. 최초 검색·최종 이동 URL·저장 보고서에 같은 규칙을 적용하며, 정보 포털끼리의 콘텐츠 비교와 유사 이름의 다른 도메인은 유지한다. 관련 회귀 5개를 추가했다.
