# 업종·경쟁사 원문 검증 — 2026-11-12

## 확인한 문제

기존 후보 선정은 제목·설명·H1의 검색어 포함 여부를 확인했지만 자사와 후보의 제공 역할을 충분히 대조하지 않았다. 재현 검사에서 병원 예약 소프트웨어가 병원 비교에, 미용학원이 미용실 비교에, 하이원 렌탈이 무주 스키 비교에 통과했다. 경쟁사 검색용 본문은 고객사 사례·관련 글을 다시 포함할 수 있었다.

## 변경

- 본 분석의 페이지 목적·업종별 구성과 동일한 기준으로 경쟁사 비교 범위를 전달한다. 후보도 실제 수집한 홈페이지의 제목·설명·H1·본문·방문 정보에서 같은 기준을 계산한다.
- 제공 업무와 상품 판매/서비스/교육/콘텐츠 유형, 확인된 세부 분야, 지역과 스키 목적지를 대조한다. 명확한 지역 근거가 있는 지역 업체는 후보의 운영 지역도 확인한다. 전국·온라인 제공이 원문으로 명시된 경우를 구분한다.
- 광고대행·소프트웨어·제조·물류 업체의 검색어에 실제 역할이 남도록 검증한다. 고객 업종, 운송하는 화물 품목, 반복 슬로건을 시장 키워드로 사용하는 경로를 차단한다.
- 고객사·관련 글·다른 지점·외부 사이트·검색 요약이 자사 키워드 원문으로 재유입되지 않도록 처리한다. 원래 수집한 메타 정보는 원문 비교용으로 보존한다.
- 제목에 상품명이 없더라도 자사 본문의 제공 내용에서 확인되면 후보가 될 수 있다. 검색 요약만으로는 통과하지 않는다.
- 후보가 이동한 최종 URL에서 자사·플랫폼·기사·중복 도메인을 다시 확인한다. 같은 도메인의 여러 검색 응답 중 관련성이 높은 페이지를 먼저 수집한다.
- 검색 결과의 명확히 다른 역할은 수집 우선순위를 낮추고, 최종 확정은 홈페이지 원문으로만 한다. 최대 8개 후보 수집 한도는 유지한다.
- 정보·콘텐츠끼리의 실제 비교는 유지한다. 상품·서비스 업체 비교의 기사 제외 규칙을 무조건 적용하지 않는다.
- 저장 보고서도 남아 있는 원문으로 명확한 업종 충돌을 걸러낸다. 후보를 제거했을 때 기존 전체 비교·포지셔닝 문구도 화면에서 제외한다. 저장 원본은 변경하지 않는다.
- 화면과 문서에 실제 비교 기준을 표시한다. 후보가 부족하면 부적합 업체로 채우지 않는다.
- 상품 판매를 명시한 인테리어 쇼핑몰이 구매 버튼 수집 여부 때문에 시공업으로 읽히던 경로도 보완했다.
- 규칙으로 고른 물류 검색어를 AI 결과라고 표기하던 출처 표시를 수정했다.

## 운영 재분석과 후속 보정

PR 164 배포 후 운영 화면에서 두 URL을 새로 분석했다. meta-hbh.com은 병의원·한방·부산 기준으로 5개 후보, mujuskiworld.com은 무주 스키 렌탈 기준으로 2개 후보를 확보했다. 병원 결과에는 의료진 이름, 입원 절차, 비급여 항목, 진료시간 및 네이버 지역 검색 API의 동일 업체 조회가 표시됐다.

추가로 확인한 오류는 경쟁사 선정 기준과 도표 설명의 업종이 별도로 선택되던 점이다. 스키 렌탈의 후보는 맞았지만 스포츠·피트니스용 회원권·락커 안내가 붙었다. 이제 원문 기반 비교 범위가 도표의 업종 기준에도 우선 적용되며, 스키와 일반 대여의 제목·설명 수정안은 별도로 제공한다. 다른 URL의 비교 범위는 재사용하지 않는다.

시즌업체 질문을 목록 순서로 연결하면서 비용 질문에 픽업 안내가 붙던 경로도 수정했다. 비용·절차 등 질문 의도에 맞는 원문을 연결하고, 편집 카드의 질문은 해당 카드의 필드와 일치시킨다. 지역명이 같은 스키 목적지로 확인되면 도·시 주소가 없는 후보를 무조건 제외하지 않되, 확인된 주소가 충돌하면 제외한다. 일반 지역명만으로는 대여업 경쟁사 검색어를 만들지 않는다.

후속 회귀 테스트 14개를 추가해 총 891개 통과, TypeScript 검사 통과. 원문이 없는 항목을 제공 사실로 채우지 않으며, 검색 응답 시점과 수집 가능 범위에 따라 후보 수는 달라질 수 있다.

최종 운영 재조회에서 무주 후보의 지역 근거가 보완되면서 관광 포털에 등록된 업체 상세페이지가 통과하는 경로를 추가로 발견했다. 관광·병원·음식점 안내 플랫폼 6개 도메인과 하위 도메인은 서비스 업체 비교에서 제외한다. 최초 검색·최종 이동 URL·저장 보고서에 같은 규칙을 적용하며, 정보 포털끼리의 콘텐츠 비교와 유사 이름의 다른 도메인은 유지한다. 관련 회귀 5개를 추가했다.

## 추가 세부 업종 검증

후속 경계 검사에서 변호사 시험 교재 쇼핑몰을 법률서비스로 읽는 경우, 반려견 훈련을 사람 대상 교육으로 읽는 경우, 같은 대분류의 헤어·네일 또는 분양·용품 업체가 지역 키워드만으로 비교에 남는 경우를 재현했다.

- 명시적인 상품 판매 정체성을 교재의 직업명보다 우선한다. 쇼핑몰 제작·업무 소프트웨어·운영 교육은 각각 대행·소프트웨어·교육으로 유지한다. 고객사 이름은 판매 정체성으로 사용하지 않는다.
- 반려견 훈련 서비스와 훈련사 자격 교육을 구분한다. 실제 Course 구조화 데이터와 사람 대상 교육은 교육 분류를 유지한다.
- 주소가 있는 의료기기·법률교재 쇼핑몰의 플레이스 업종도 소매로 연결한다. 상품에 등장한 치과·변호사를 해당 매장의 진료·법률 업무로 사용하지 않는다.
- 식당 메뉴 계열, 헤어·네일·피부관리·왁싱, 동물 분양·입양과 용품 판매, 세무·회계, 촬영·생활가전 등 대여 품목, 사진촬영·웨딩 등 세부 업무를 비교한다. 카페는 커피·베이커리·케이크 근거를 구분한다.
- 제목의 주업무를 우선하되, 다른 서비스도 실제 제공한다고 명시한 자사 문장은 겹치는 제공 범위로 인정한다. 브랜드명만 있는 경우에는 고객 사례·관련 글·후기를 제거한 본문의 시술 메뉴 등으로 보완한다. 미제공 문구는 제공 근거가 아니다.
- 같은 시즌 태그만으로 서로 다른 제공 업무를 통과시키지 않는다. 업무와 시즌 조건을 각각 대조한다.
- 이전 저장 범위에 세부 분야가 비어 있으면 저장한 실제 제목·설명·H1에서만 보완한다. 명확히 다른 후보와 그에 기반한 전체 비교 문구를 화면에서 제외한다. 근거가 없는 저장 후보를 새로 부적합하다고 단정하거나 저장 원본을 변경하지 않는다.
- AI 업종 제안은 인용 문구가 원문에 존재하는지와 그 문구가 제안 업종을 뒷받침하는지를 함께 확인한다. 일반적인 ‘상담 문의 안내’만으로 의료·법률 업종을 승인하지 않는다.

추가 회귀 검사 28개는 합성 HTML을 원문 수집·분류·후보 최종 선정·저장 보고서 표시 경로에 통과시킨 검사다. 기존 896개와 합쳐 924개를 확인한다. 별도로 기존에 수집한 10개 URL 원문을 재실행했으며 병원, 스키, 물류, 법률, 여행, 커뮤니티, 상품 판매 분류가 유지됐다. 이 10개 재검사는 새 크롤링이나 네이버 검색 API 실호출이 아니다. 전체 업종에 공통 검증 경로를 적용했으며, 모든 실재 업체·URL의 정확성을 전수 확인했다는 의미는 아니다.

## 부가 설명이 업종을 바꾸는 경로 검증

추가 검사에서 여행용품 쇼핑몰→여행사, 해외이사 포장박스 판매→국제물류, 한의원의 호주산 영양제 소개→건강식품 판매, 렌터카·스키렌탈·미용실·반려견 호텔의 보험 안내→보험업 전환을 재현했다. 여행 매거진과 해외이사 블로그도 콘텐츠 정체성보다 특화 사업 판별이 먼저 적용되는 문제가 있었다.

특화 사업 판별에 홈페이지의 실제 제공 역할과 방문 업종을 함께 적용한다. 상품의 사용 목적·업종 관련 글·이용조건의 보험 단어가 판매/서비스/콘텐츠 구분을 바꾸지 못하도록 했다. 숙박업체는 객실·체류·예약 기준을 유지하고, 세무사 사무소의 변호사 의뢰 안내는 직접 법률서비스로 사용하지 않는다.

지역 업종 24종의 보험 부가 안내를 검사했다. 정확한 비교 통계 분류가 없는 문화시설·생활서비스 등은 그 사실을 유지하며, 보험 문구 때문에 금융업 비교로 넘어가지 않는다. 해당 업종의 분석 구성은 그대로 사용한다. 렌터카는 자동차 분류로 연결하고, 경쟁사 검색에서 '보험' 대신 '렌터카'를 정상적으로 사용할 수 있도록 했다. 보험사·여행사·물류업체·건강식품몰의 정상 분류와 후보 제외의 반대 사례도 검사했다.

추가 41개를 포함한 총 965개 자동 테스트 및 TypeScript 검사 통과. 새 검사는 합성 HTML을 실제 수집·분류·분석 구성·후보 선정 코드에 넣은 회귀 검사다. 기존 수집 원문 10개 재실행에서도 주요 분류가 유지됐다. 모든 실재 URL의 실시간 전수 검증이나 네이버 검색 API 재조회 결과라는 의미는 아니다.

## 고객 대상·취급 상품·종료한 서비스 추가 검증

반려동물 사진관을 반려동물 매장으로, 식당 식자재 판매점·치과 장비 판매점을 식당·치과로 분류하는 경로를 재현했다. 직접 제공하는 촬영·법률 등 구체적인 업무를 반려동물이라는 고객 대상보다 우선하고, 판매점·용품점·서점의 명시적 소매 정체성을 상품 이용 업종보다 우선한다. 온라인 상품몰과 방문 구매 매장의 기존 목적 구분은 유지한다.

“네일은 제공하지 않으며 헤어 커트를 시술합니다”에서 헤어까지 사라지는 경우와 “네일 서비스를 종료했고”가 네일 제공 근거로 남는 경우를 함께 수정했다. 문장 안의 별도 절을 나누어 현재 제공하는 부분만 분류·세부 업무·플레이스 서비스어·시즌 정보에 사용한다. 원문은 변경하지 않는다. 서비스 제공 동사가 없는 별도 안내 문단을 다른 문단의 제공 동사에 연결해 추가 업무로 해석하지 않는다. 동시에 제공한다고 명시한 복수 서비스는 모두 유지한다.

사진관·장례·세탁·세무 업체의 경쟁사 검색어에는 실제 업무 표현이 남도록 했다. 같은 고객 대상 또는 지역명만 겹치는 매장·병원·식당은 최종 후보에서 제외하며, 같은 역할의 정상 후보는 통과한다. 네이버 지역 검색 응답의 업종 대조도 동일한 우선순위를 사용한다.

새 회귀 검사 29개를 포함한 총 994개 테스트와 TypeScript 검사가 통과했다. 검사에는 실제 추출 코드에 합성 HTML을 넣은 분류·분석 구성·후보 최종 선정과 모의 API 항목 대조가 포함된다. 기존 실제 수집본 10개 재실행에서도 병원·물류·여행·법률·스키·커뮤니티·쇼핑몰 분류가 유지됐다. 신규 4개 URL의 로컬 추출 시도는 실행 환경의 DNS 오류(EAI_AGAIN)로 완료되지 않아 라이브 검증 건수에 포함하지 않았다. 별도 브라우저에서 meta-hbh.com의 현재 병원 소개·진료과목·의료진·주소·시간 안내를 직접 확인했다. 이 단계의 결과는 새 네이버 API 검색이나 전체 실제 URL 전수 검증을 의미하지 않는다.
