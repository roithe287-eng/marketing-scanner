# GEO 안내 및 운영 경쟁사 연동 검증

확인일: 2026-10-01. GEO 안내는 PR #9, 운영 커밋 `d376fb7a7fed03b0cd5682f44ab242152729e307`에 반영했습니다.

## 반영 내용

- 영역별 점수 다음에 GEO의 뜻과 세 지표(페이지 준비도, 브랜드 언급, 자사 출처 인용)를 먼저 설명합니다.
- 콘텐츠 준비도 제목과 OpenAI·Gemini 답변 제목/펼치기 항목에 GEO를 명시합니다. 브랜드 언급과 실제 자사 URL 출처 인용을 구분하며, 구버전 결과의 측정 한계 안내를 유지합니다.
- 원본 결과와 공유 보고서는 같은 안내 컴포넌트를, PDF는 같은 설명 문자열을 사용합니다.
- GEO 설명의 근거: https://arxiv.org/abs/2311.09735 . 노출 증가율이나 인용 보장은 주장하지 않습니다.

## 실제 운영 연동 결과

`https://www.mktscanner.com/`에서 `https://prorealmkt.com`을 입력하고 새 분석을 실행했습니다. 원본 분석 → 경쟁사 비교 완료 → 공유 버튼 → 새 공유 페이지 → 전체 PDF 다운로드를 실제 브라우저에서 확인했습니다.

| 확인 항목 | 관측 결과 |
| --- | --- |
| 네이버 환경 설정 | NAVER_CLIENT_ID, NAVER_CLIENT_SECRET이 Production에 설정되어 있음. 값이나 적용 환경은 변경하지 않음 |
| 경쟁사 검색 키워드 | 광고대행 |
| 비교 결과 | 5개 후보, 포지셔닝 맵·메시지 클러스터·강약점 표·카드 표시 |
| 후보 도메인 | 10wol.com, humetro.busan.kr, boostweb7.com, adturekorea.co.kr, jm-ad.kr |
| 공유 결과 | https://www.mktscanner.com/r/p5mrzi9xasns 를 새로 열어 GEO 설명과 5개 비교 결과 유지 확인 |
| PDF 결과 | 38페이지 / 5.5초 / 10,478,621바이트. 링크 주석 30개 중 경쟁사 URL 5개 확인 |
| PDF 시각 점검 | GEO 안내·실행 과제, 경쟁사 상세 마지막 부분, 최종 페이지를 렌더링하여 줄바꿈·푸터와 최종 내용 확인 |
| AI 답변 | OpenAI 정상 응답 5개. Gemini 5개는 HTTP 429로 별도 실패 안내 유지 |

경쟁사 목록은 네이버 웹문서 검색의 상위 후보입니다. 검색어와 관련된 광고문의 기관 페이지도 포함될 수 있으므로, 이 검증은 실제 API 연동과 표시·저장·다운로드 성공을 확인한 것이며 5개 모두가 같은 서비스를 판매하는 직접 경쟁사임을 보장하는 검증은 아닙니다.

## 검사 및 접근 정책

- GEO 변경의 자동 테스트 22개, 프로덕션 빌드, 타입 검사 및 `git diff --check` 성공.
- 사용자 승인 범위에 따라 운영 분석·경쟁사·공유를 실제 검증하는 동안만 시간 제한 IP 예외를 적용했습니다. 연동 검증을 마쳐 예외를 코드에서 제거합니다. 기존 IP/쿠키 정책을 복원하며 공개 공유 페이지와 PDF 접근은 유지합니다.
- 검증용 페이지나 환경변수 변경은 없습니다. 리드/연락처 제출 및 Slack 알림은 실행하지 않았습니다.
- 기존 미리보기 환경의 경쟁사 성공 검증 경계는 이번 운영 검증으로 보완했습니다.
