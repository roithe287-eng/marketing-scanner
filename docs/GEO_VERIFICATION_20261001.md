## 확인 범위와 남은 외부 조건

- Gemini는 현재 연결된 계정에서 HTTP 429를 반환한다. 사용량·요금제·모델 접근 설정을 계정 소유자가 확인해야 하며, 결제 설정은 변경하지 않았다. 실패 상태 처리까지 검증했고 Gemini 정상 실응답은 검증하지 못했다.
- 네이버 API 키가 미리보기 환경에 없어 실시간 경쟁사 수집은 이번 브라우저 검증 범위에 포함하지 않았다. 운영 키나 값은 변경하지 않았다.
- 메인 화면의 연락처 제출은 외부 알림을 보내므로 시험 연락처를 제출하지 않았다. 공유 화면에서 동일한 PDF 내보내기 함수를 직접 실행해 파일 생성 경로를 검증했다.
- PDF는 빠진 상세가 없도록 전체 데이터를 담는다. 긴 보고서는 페이지 수에 비례해 생성 시간이 늘며, 페이지별 진행과 완료 시간을 표시한다. 화면과 같은 그래프 캡처 대신 별도 문서 구조로 정리한다.
- 옛 미리보기 배포에 남은 임시 예외는 코드에 지정된 2026-10-01 03:00 UTC에 자동 만료된다. 운영에는 적용된 적이 없고 최종 브랜치에는 해당 코드가 없다.
- 새로운 질문과 AI 응답의 내용은 시점과 제공자에 따라 달라진다. 위 결과는 관측한 조건의 검증 기록이며 모든 입력에서 무오류를 보증하지 않는다.
