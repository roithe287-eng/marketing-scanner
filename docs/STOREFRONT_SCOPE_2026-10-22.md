# 동적 상품 정보의 진단·질문 연결

온누리스토어 재진단에서 공개 상품 12개는 수집됐지만 후기·가격·CTA의 HTML 미감지를 실제 부재로 표현하고, FAQ와 GEO 질문은 상품 보완 자료 없이 브랜드·일반 서비스로 생성되는 경로를 확인했습니다.

- `storefrontEvidence.ts`는 공개 상품 목록 또는 JS 페이지의 확인된 상품 보완이 있을 때, HTML에서 관측하지 못한 제목·구매 버튼·후기·인증·가격·연락처를 실제 화면 대조 항목으로 구분합니다. 요약·체크리스트·핵심 이슈·빠른 개선·로드맵·상담 안내에 조건부 실행 지침을 적용합니다. 실제 수집된 값과 점수를 상품 목록으로 대체하거나 가산하지 않습니다.
- FAQ의 상품 자료는 별도 `product` 원문 종류와 URL로 보존합니다. 상품명·분류는 키워드와 질문 주제에만 쓰고 답변 근거에는 사용할 수 없습니다. 페이지 본문만 검증된 답변 문장의 출처로 사용합니다. 상품 보완이 있는 경우 브랜드·슬로건 단독 키워드는 배제하며, HTML 관측은 그대로 유지합니다.
- GEO 질문은 실제 상품군 표본을 전달하고, 생성 실패 시에도 확인한 상품 카테고리로 5개 질문을 구성합니다. 브랜드 질문에 도메인을 함께 표기해 동명 업체를 구분합니다. 캐시 버전과 입력 식별에 상품 보완을 포함합니다. 직접 입력 질문과 비교용 고정 질문은 유지합니다.
- 보고서 스키마는 새 자료와 범위를 선택적으로 확장해 이전 공유 보고서를 계속 읽을 수 있습니다. FAQ 화면·공유·PDF에는 상품 표본 근거와 한계를 표시합니다. 진단 방식은 v7로 분리합니다.

검증: 경쟁사 교정 통합 자동 검사 306개, TypeScript, 프로덕션 빌드 통과. 미리보기 온누리스토어 재진단에서 상품 12개, 비타민·구강청결제·스킨케어 키워드, 상품군 기반 FAQ·GEO 질문과 수집 범위를 구분한 요약을 확인했습니다. 경쟁사 품목·커머스 교정(#82)을 통합한 검사와 빌드도 통과했습니다. 실제 운영 결과는 배포 후 재진단으로 확인합니다.
