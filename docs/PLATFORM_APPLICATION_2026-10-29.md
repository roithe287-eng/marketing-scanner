## 제공 기능

- 카페24·고도몰·메이크샵·아임웹·기타/독립몰 아이콘을 선택하면 설정 방법을 펼친다.
- 공개 HTML의 제작 도구 단서를 먼저 제안하되 복수/미확인은 확정하지 않는다.
- 검색 제목·설명, 첫 화면 문구, 버튼 문구·연결, 질문·답변, 검색도구 인증 태그의 입력 위치·순서·완료 확인을 제공한다.
- 기존 진단에서 만든 수정값을 텍스트로 연결하고 개별 값 또는 전체 설정 방법을 복사한다. 질문·답변은 원래 보고서 영역으로 연결한다.
- 화면·공유 결과·전체 PDF는 같은 설정 절차를 사용한다. 알려지지 않은 독립몰 파일명·관리자 경로는 추정하지 않는다.

## 제거한 범위

- 추가 본문 HTML 생성, 디자인 미리보기, FAQ 재편집·HTML 포함 선택, 새 코드 위젯 설치 안내를 제거했다.
- 앞서 추가한 저작권·라이선스 부연설명 배너와 복사본·PDF의 반복 안내를 제거했다.
- 웹·Pocket의 별도 폰트 패키지/불러오기, PDF의 사용자 정의 폰트 대기와 지정, 브랜드 SVG의 특정 폰트 지정을 제거했다.
- 사이트는 시스템 기본 글꼴로 렌더링하며 CSP의 font-src none으로 별도 폰트 다운로드를 막는다.
- 경쟁사 파비콘을 외부 서비스에서 가져오던 호출도 제거했다. 비교는 순번·도메인·제목으로 제공한다.
