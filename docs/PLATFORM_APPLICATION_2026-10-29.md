# 플랫폼별 적용 패키지

검색 챕터의 ‘플랫폼별 적용’에서 카페24·고도몰·메이크샵·아임웹·기타/독립몰 아이콘으로 가이드를 펼친다. 감지된 제작 도구 하나가 있으면 해당 가이드가 먼저 열린다. 복수 도구 또는 미확인은 기타 가이드로 시작하고 다른 플랫폼을 선택할 수 있다. 가이드 선택은 수집한 감지 결과를 변경하지 않는다.

## 제공 범위

- 같은 URL의 저장된 원문과 검색 제목·설명, 첫 화면 제목·소개, 행동 버튼의 적용 초안을 비교하고 편집·복사한다.
- 제목에 주제와 브랜드가 이미 있으면 유지한다. 신뢰도가 낮거나 ‘상담’ 같은 일반어는 SEO 제목을 새로 만드는 근거로 쓰지 않는다. 설명은 완전하게 저장된 검색 설명 또는 수집 본문을 사용한다. 원문이 없으면 작성 필요로 둔다.
- 답변 근거가 있고 누락 정보가 없는 FAQ만 HTML에 기본 포함한다. 확인 대기 답변은 작성 후 사용자가 포함을 선택한다. 답변·질문을 편집하면 확인 선택이 해제된다. 괄호 작성 틀은 HTML에서 제외한다.
- 별도 본문 구역용 HTML을 제공한다. 텍스트와 속성을 이스케이프하고 스크립트·폼·추적 태그는 만들지 않는다. 유효한 HTTP(S) 주소가 없으면 CTA 링크를 제외한다. 추가 구역은 H2를 사용하고 기존 대표 H1은 별도로 수정한다.
- 플랫폼별 입력 위치·작업 스킨·기본 위젯·PC/모바일 확인 방법과 공식 도움말을 제공한다. 원본 소스 파일명·관리자 내부 상태를 공개 URL로 추정하지 않는다.
- 기타 가이드는 WordPress/Shopify/Wix 또는 직접 제작/미확인 방식으로 선택할 수 있다. Next.js·Vercel·Cloudflare는 CMS 확정 근거로 사용하지 않는다.

## 수집과 저장

`siteEditing.signals`에 `godomall`, `makeshop`을 추가했다. 기존 version 1 보고서와 호환된다. 제작 도구 감지는 generator, 스크립트/스타일, 고유한 스킨 구조를 활용한다. 네 플랫폼의 이미지 핫링크와 본문 속 플랫폼 이름만으로 확정하지 않는다. 별도 관리자 탐색·추가 크롤링·추가 AI 요청은 하지 않는다.

패키지는 저장 보고서에서 동일하게 파생되며 공유 화면과 전체 PDF에도 최초 초안을 제공한다. 화면에서 편집한 값은 자동 저장하지 않고 ‘적용 패키지 전체 복사’에 반영한다. PDF에는 진단 당시 초안임을 표시한다. 기존 문구 개선 화면의 제목·설명도 같은 값을 사용한다.

## 적용 경계

가이드는 자동 설치나 게시 기능이 아니다. 본문 추가용 HTML은 전체 테마 교체본이 아니다. 카페24 모듈·고도몰 치환코드·메이크샵 가상태그를 유지한다. 원본 파일 전체 교체가 필요하면 실제 소스/스킨과 편집 권한을 확인해야 한다. 가격·성과·효능·자격·법적 적합성은 자동 검증하지 않는다.

기존 전체 보고서는 계속 펼쳐진 상태로 유지한다. 이번 플랫폼 선택·근거·HTML 보기만 요청에 따라 접을 수 있다. 기존 커머스 레이더 및 비커머스 업종 진단의 산식은 변경하지 않는다.

## 검증

- 플랫폼 4종 감지와 복수/미확인, 유사 도메인·이미지·전송 서버의 오감지를 검사한다.
- 같은 URL의 원문 연결, 잘린 메타데이터, 저장 원문이 없는 보고서, 다른 URL의 답변 계획을 검사한다.
- 미완성 FAQ 제외, HTML 이스케이프, 잘못된 URL 차단, 복사/PDF 기본 초안 일치를 검사한다.
- 실제 React 컴포넌트의 아이콘 전환·입력·확인 체크·미리보기·복사와 320/390/768px 및 데스크톱 배치를 브라우저에서 확인한다.
- 가상 화면 fixture는 preview 전용 경로에만 연결하며 production에서는 해당 경로가 404를 반환한다.
