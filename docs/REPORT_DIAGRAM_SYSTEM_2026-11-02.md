# 결과 보고서 전체 도식과 읽기 구분 · 2026-11-02

핵심요약의 첫 두 구간을 유지하면서, AI·GEO·검색·경쟁사·실행 과제까지 도식과 읽기 표시를 확대했다.

- 기존 첫 세 구간의 도식은 유지하며 페이지 모형을 정교한 SVG로 교체했다. 첫 화면·검색 결과·비용·FAQ·증빙·문의 버튼·이미지·설정·진행의 9종이다. 텍스트는 이미지에 넣지 않고 실제 HTML로 표시해 작은 화면과 확대에서도 읽을 수 있다.
- 28개 하위 구간에 흐름·대조·가지형·재확인·수식 도식을 정의했다. 과제가 없는 이전 보고서에는 완료 건수를 꾸미지 않고 실행 방식의 개념도를 제공한다.
- 숫자는 저장된 고유 문구·주소·후보·과제·이슈·기간별 작업 수만 사용한다. 개념도와 보고서 집계를 표시하며 점수·관측·원문·순위·측정 산식은 변경하지 않는다. 목표 계산 도식은 목표 완료 ÷ 현재 완료 비율 = 필요 유입이며 현재 비율 유지 가정이다.
- 핵심요약(파랑), AI·GEO(보라), 검색·페이지(청록), 경쟁사(황갈색), 실행 과제(청회색)로 장을 구분한다. 각 하위 구간에 번호·라벨·구분선을 넣었다.
- 현재 근거(슬레이트), 해석·조건(호박색), 수정 제안(민트), 적용 위치(파랑), 완료 확인(보라)의 역할 색을 보고서 전체에 연결했다. 라벨과 아이콘을 함께 사용하며 상태 판정의 색과는 구분한다. 동일 역할 팔레트를 사용하는 상세 PDF에도 색이 이어진다.
- 상세 실행 가이드의 compact 모드에도 주제별 페이지 모형을 제공한다. 원문, 복사 내용, 상세 단계, 기본 펼침, 목차와 깊은 링크는 유지한다.
- 모바일은 흐름을 세로로, 가지형은 공통 연결선으로 재배치한다. 비교는 양방향, 계산은 나눗셈·등호로 표현한다. SVG에 공유 ID나 외부 이미지 요청이 없으며 애니메이션·외부 라이브러리도 추가하지 않는다.

검증: 전체 섹션의 도식 누락, 집계 일치, 저장 데이터 불변성, HTML 이스케이프, 벡터 9종, 색상 대비, 기존 보고서 회귀 검사와 운영 빌드. 화면 검수는 미리보기 전용 가상 보고서의 PC·390px·320px에서 수행한다. 일반 스토어의 제한 분석 정책과 잠긴 예시 판정은 유지한다.
