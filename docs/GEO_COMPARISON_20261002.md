# 같은 질문으로 GEO 이전·현재 비교

공유 보고서 링크 또는 ID를 기준으로 URL·질문·유형·고객 여정을 불러온다. 서버에서 기준 보고서를 다시 조회하고 URL 및 질문 변경을 거부한다. 재측정은 완료된 관측 캐시를 건너뛰며 질문 생성도 하지 않는다.

비교는 질문 문자열(앞뒤 공백 제거)과 엔진으로 연결한다. 요청 모델, 요청 본문의 해시, 최종 타겟 URL, 브랜드 판정 기준, 측정 프로토콜이 같고 양쪽 모두 검색·출처 확인이 끝난 정상 관측만 사용한다. 현재 관측은 새 시각이며 캐시 재사용이 아니어야 한다. 중복·누락·실패·이전 조건 기록 없음·조건 변경은 명시적으로 제외한다. 이전/현재 인용률은 동일한 질문·엔진 쌍을 분모로 계산하고 브랜드 언급도 값이 있는 동일 쌍만 계산한다. 유효 쌍이 0이면 0%가 아닌 비교 불가로 표시한다.

요청 모델 이름과 설정이 같더라도 제공사 내부 모델이나 검색 색인은 변할 수 있다. 관측 변화는 사이트 수정의 인과 효과나 시장 전체 노출 변화가 아니다.

기준 보고서 전체를 중첩 저장하지 않고 해당 GEO 관측만 새 결과에 저장한다. 공유 스키마와 PDF에 이전 답변·출처·제외 사유를 유지한다. 화면에서 상세를 펼칠 때 외부 API를 호출하지 않는다.

검증: 회귀 테스트 37개, TypeScript, Next.js 프로덕션 빌드 통과. 실제 화면 및 배포 검증은 아래에 기록한다.
