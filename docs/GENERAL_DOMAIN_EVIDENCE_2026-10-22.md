# 일반 도메인 공통 상품·경쟁사 점검

## 적용

온누리스토어 전용 공개 상품 API만 호출하던 메인 분석 경로를 모든 일반 도메인의 공통 수집 단계로 교체합니다. 네이버 스마트스토어·브랜드스토어는 기존 제한 분석을 유지합니다.

1. 최초 페이지에서 Product JSON-LD, 공개 상품 hydration JSON, Product microdata, 상품 카드와 상품·분류 링크를 읽습니다. 원본 HTML은 추가 보관하지 않고 필요한 공개 필드만 다음 단계로 전달합니다.
2. 자사 상품 링크, 관측한 공개 분류 페이지, robots에 선언된 사이트맵 및 표준 사이트맵, 공식 검색 API의 자사 상품 URL 순으로 보완합니다. 온누리스토어의 명시적 공개 API 어댑터는 유지하되 다른 도메인의 임의 API 주소를 추측하지 않습니다.
3. 카페24·고도몰·영카트·메이크샵·아임웹·Shopify에서 쓰이는 일반 상품 URL 형식을 지원합니다. 각 플랫폼의 전체 구현이나 브라우저 렌더링을 검증한 것은 아닙니다.
4. 검색 요약과 사이트맵은 URL 발견에만 사용합니다. 상품명·분류·설명은 해당 사이트에서 직접 확보한 원문으로 한정합니다. 보완 상품 자료로 가격·재고·고객·주문 상태를 수집하지 않습니다.
5. 동일 상품의 이미지·상품명 링크를 중복 표본으로 계산하지 않습니다. 서로 다른 상품 12개까지 보존하고 상품 상세는 최대 4개, 분류 페이지와 사이트맵은 각각 최대 2개를 확인합니다. 입력 페이지를 포함한 HTML/XML 문서 수집 시도는 최대 9개이며 robots 요청과 리디렉션은 별도입니다. 메인 보완은 7초, 경쟁사 원문 보완은 12초 한도입니다. 시간 초과 경로도 표본 한도를 지킵니다.
6. 추가 요청은 공개 주소 검증, 동일 도메인·프로토콜, robots 규칙을 거칩니다. 수집 제한을 실제 부재로 바꾸지 않고, 최초 페이지에서 이미 확인한 공개 상품 정보는 추가 수집 실패 때문에 폐기하지 않습니다.
7. 메인 진단·FAQ·GEO·업종 분류는 같은 상품 보완 자료를 사용합니다. 입력 페이지 H1·본문·스키마 등 원래 SEO 관측은 유지합니다. 서비스형 사이트를 상품 미수집만으로 쇼핑몰로 분류하지 않습니다.
8. 경쟁사 분석은 일반 업종 키워드가 있는 경우에도 자사 상품 원문을 확인합니다. 판매가 확인된 사이트는 구매 의도로 검색하고 판매 단서가 없는 정보 사이트를 제외합니다. 채용·기업정보·관련성 미확인 후보를 수를 채우기 위해 포함하지 않습니다.
9. 동적·상품 페이지의 미감지 기능은 실제 화면 대조로 안내합니다. 상품 표본이 있는데 전체 상품 부재를 주장하는 이슈는 보류합니다. 진단 방식은 v8로 분리하고 기존 공유 보고서와의 호환성을 유지합니다.

## 검증과 경계

자동 검사 325개(일반 도메인 검사 19개 포함), TypeScript 및 프로덕션 빌드로 확인합니다. 이전 작업에서 윈세이 실제 공개 원문에서 서로 다른 상품 12개를 인식했고, 이번에는 복원한 변경분을 다시 검사합니다. 자동 검사는 상품 URL·원문 수집·중복 제거·수집 제한·시간 초과·서비스형 사이트·상품군 FAQ/GEO·경쟁사 관련성·원본 SEO와 공유 스키마를 포함합니다.

모든 일반 도메인이 공통 점검을 거치지만 모든 페이지·상품·JS 렌더링·내부 API를 전수 수집하는 기능은 아닙니다. 공개 경로·접근 규칙·응답 시간에 따라 미확인 상태가 남을 수 있습니다. 표본으로 매출·주력 상품 순위를 단정하지 않습니다. 기존 저장 보고서는 새로 진단해야 새 기준이 적용됩니다.
