# 시각형 마케팅 진단 보고서

## 품질 기준

- 준비도 점수, AI 관측, 실행 과제를 서로 다른 시각 요소로 표시한다. 준비도 점수를 인용률로 읽거나 실패를 0점으로 해석할 수 없어야 한다.
- 모든 차트에 값·분모·상태 이름을 함께 표시한다. 0건의 유효 관측은 ‘판정 불가’, 유효 관측에서 0회 인용은 0%로 구분한다.
- 준비도 항목, 질문 필터, 질문 선택, 근거 상세 확장은 추가 네트워크 호출 없이 동작한다.
- 공유 보고서는 저장된 원문을 그대로 사용한다. PDF 앞부분에 시각 요약을 추가하고 모든 원문·출처·제외 사유는 상세 본문에 보존한다.
- 390px 화면에서 글씨를 축소한 전체 그림을 넣는 대신 카드와 표를 재배치한다. 키보드 포커스·누른 상태·텍스트 범례를 제공한다.

## 추가 아이디어와 우선순위

1. **질문 → 답변 페이지 지도**: 고객 질문별로 자사 페이지, 실제 답변 문장, 확인 시각을 연결한다. 미수집 페이지는 ‘답변 없음’으로 단정하지 않는다. 다음 개발의 최우선이다.
2. **콘텐츠 보완 카드**: 현재 답변·부족한 근거·추가할 항목을 나란히 제시한다. 확인하지 않은 가격, 후기, 성과 수치는 생성하지 않고 입력이 필요한 사실로 표시한다.
3. **경쟁사 메시지 공백 지도**: 자사와 승인한 경쟁사 후보의 가격/신뢰/전문성/지원 범위를 매트릭스로 비교한다. 수집 실패는 빈값으로 유지하고, 실제 고객층이 다른 업체는 승인 전 후보로 구분한다.
4. **출처 검토함**: AI가 인용한 자사·외부 URL을 묶어 오래된 정보, 잘못된 서비스 설명, 끊어진 링크를 사람이 검토하고 근거를 남긴다. 최초 단계는 읽기·분류 기능부터 시작한다.
5. **수정 전후 작업 기록**: 무엇을 수정했는지와 수정 URL·화면·날짜를 GEO 관측에 함께 연결한다. 동시 발생한 변화만으로 수정 효과를 단정하지 않는다.
6. **광고주용 1페이지 요약 모드**: 의사결정에 필요한 현황·세 가지 과제·근거 링크만 별도 인쇄하고 전체 상세 보고서로 연결한다. ‘완료’는 자동 점수로 추정하지 않고 작업 증거가 있을 때만 표시한다.

복잡한 네트워크 그림이나 레이더 차트를 모든 지표에 반복 적용하지 않는다. 크기 비교는 막대, 구성은 누적 막대, 질문×엔진은 매트릭스, 작업 순서는 흐름도가 적합하다. 예상 매출이나 인용 확률을 만들어 그래프를 채우지 않는다.
