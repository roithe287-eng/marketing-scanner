## 실제 수집과 제한

2026-11-03 공개 메인·상세·이용안내를 조사했다. 알려진 URL 목록은 추가 수집의 출발점이며 분석 결과 자체가 아니다. 매 진단에서 현재 공개 HTML을 다시 읽고, 검색 요약은 직접 읽은 원문과 구분한다.

- 보완 수집은 같은 사이트의 공개 페이지 최대 3개, 전체 문서 최대 4개, 기본 6초. 기존 상품 수집과 병렬 실행해 기존 분석 요청의 시간 예산을 유지한다.
- robots, 공개 URL 검증, 사설 IP 차단, 동일 사이트 리다이렉트 검증과 응답 크기 제한을 그대로 적용한다. 실패한 보완 요청은 메인 페이지의 기존 근거를 지우지 않는다.
- Shopify의 `%2B` 등 필터 전용 robots 규칙이 관련 없는 ASCII 공개 상세 경로까지 미확인으로 만들던 문제를 수정했다. 인코딩된 비예약 문자는 정규화하고, 비ASCII 규칙/경로의 보수적 재확인은 유지한다.
- 트립호주 robots는 조사 시점에 `User-agent: * / Disallow: /`와 특정 검색 로봇 허용 목록을 사용하며 JinjjaScanner는 허용 목록에 없다. 다른 로봇으로 위장하거나 차단된 HTML을 요청하지 않는다.
- 이 경우 기존 네이버 웹 검색 API로 같은 도메인의 공개 결과를 조회해 검색 요약 기반 제한 진단을 제공한다. HTML·본문 답변·버튼·가격·기능 유무와 예약 동작을 검증한 결과가 아니다. 검색 요약은 답변 사실·HTML 통과/실패·AI 입력 원문으로 사용하지 않는다. API도 이용할 수 없다면 기존 차단 안내를 유지한다.
- 운영자가 JinjjaScanner에 공개 경로 수집을 허용하면, 특정 에이전트 허용 규칙을 존중하여 일반 원문 진단으로 복귀한다.
- 제한 진단은 낮은 점수나 취약 등급으로 표시하지 않는다. 기존 레이더 위치와 8개 축은 유지하되 미측정·평가 보류로 표시하고 업종 표본 저장에서도 제외한다.
- 메인 HTML의 H1·메타·CTA·상품·구조화 데이터 개수에 보완 페이지를 합산하지 않는다. `<svg><title>`도 문서 검색 제목과 개수에 합산하지 않는다.
- CSS, 번역 사전, 인증·고객 상태, 후기·댓글은 보완 사실 추출에서 제외한다. 공개 여행 카탈로그의 이름/설명만 정해진 필드로 수집한다.
- FAQ 답변 근거는 서로 다른 상품·옵션의 조건을 하나의 답변 사실로 합치지 않는다. 확인한 문서 URL은 보고서의 기존 원문·링크 모음과 PDF에 보존한다.
