# 마케팅스캐너 결과 신뢰성·안정성 점검 — 2026-10-05

## 이번 변경의 범위

웹사이트의 진단 계산, 수집 원문, 경쟁사 비교, GEO 판정, 저장·공유·PDF 경로를 점검했다. 보류 중인 앱 소스와 운영 접근 정책은 변경하지 않았다. 이 점검은 AI가 작성하는 모든 자유 서술의 사실성, 고객 사이트의 실제 성과, 서비스 무중단을 인증하는 작업은 아니다.

## 검증

- 단위·회귀 테스트 166개 통과. 새 신뢰성 테스트 12개 포함.
- 실제 로컬 Redis 7.4.2와 Upstash SDK 브리지 통합 테스트 5개 통과: 승인·활성화·권한·동시 요청·한도·정지·저장 소유권·표본 중복·만료·환경 분리·저장 원자성.
- TypeScript 검사 및 프로덕션 빌드 통과.
- 프로덕션 빌드를 사용한 로컬 브라우저 시나리오 8개 통과: 중복 제출, 잘못된 응답에서 이전 결과 보존, 오래된 경쟁사 응답 차단, 게이트웨이 오류, 공유 재시도, 상세 분석 오류 복구, 신뢰성 표시·CPA 계산, 권한 확인 실패 시 차단.
- 320 / 390 / 768 / 1440px 화면 폭에서 가로 넘침 없음. 브라우저 미처리 오류 0개. PC·모바일 화면 육안 확인.
- 웹 화면과 PDF 문서 생성에서 구형 표본·임의 절감액이 다시 노출되지 않음을 검증.

브라우저 결과 화면 검증은 로컬 테스트 응답을 사용했다. 운영에 승인된 진단 계정이 없어, 실제 운영 계정으로 유료 외부 API 진단 → 저장 → 재접속의 전체 경로를 실행하지 않았다. 운영 반영 후에는 배포 커밋·READY 상태와 공개 화면·접근 제한을 확인한다.

## 남아 있는 확인 범위

- AI 자유 서술·업종 분류는 해석 오류가 가능하다. 원문 일치는 해당 페이지의 주장 자체가 사실임을 증명하지 않는다.
- 정적 HTML 수집은 렌더링 후 화면, 관리자 로그인 내부, 실제 전환·색인·광고 계정 상태를 실측하지 않는다.
- 반복 진단의 점수 변동은 실제 성과 변화나 개선 작업의 인과 효과를 뜻하지 않는다.
- 사업자 동일성은 도메인·식별 가능한 플랫폼 계정 단위로 보수적으로 판정한다. 별도 도메인 간 동일 사업자 여부나 모든 공유 플랫폼을 확정하지 않는다.
- 새 표본 집계는 기존의 검증 불가능한 표본을 승계하지 않는다. 표본이 적으면 수치 대신 상태를 표시한다.
- 광고비 시나리오의 사용자 입력값은 화면에만 유지된다. 공유·PDF에 해당 실적을 저장했다고 표시하지 않는다.
