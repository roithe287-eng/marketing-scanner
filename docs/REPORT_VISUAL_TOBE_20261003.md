# 8방향 시각화와 반복 표현 TO-BE

## 완료 기준
- 기존 8개 영역의 점수·레이더·색상 구분을 유지하며 처음부터 보이게 한다.
- 선택한 영역의 점수와 검토 가이드가 연결되고 8개 버튼 모두 키보드로 조작 가능하다.
- 320~767px에서는 차트와 카드가 세로 배치, 1024px 이상에서는 병렬 배치된다. TO-BE 비교는 모바일 1열, 데스크톱 2열.
- 원래 빈도 데이터와 근거 문구를 보존하고 반복 횟수만으로 과잉·적정 밀도·SEO 효과를 주장하지 않는다.
- 브랜드 식별, 부정·예외 조건을 훼손하는 자동 삭제를 제안하지 않는다.
- 실제 문장 원문이 없는 항목은 사실을 채워 쓰는 작성 틀로 명확히 표시한다.
- 공유 화면과 최초 분석은 같은 컴포넌트를 사용한다. PDF에는 시각 요약과 모든 TO-BE 상세가 포함된다.

## 적용한 아이디어
- 기본 노출 8방향 레이더와 영역 선택형 가이드
- 낮은 점수 순으로 연결한 우선 검토 3개 영역
- 유지·구체화·정리·배치·문맥 검토의 5가지 수정 방향 카드
- 단어/연속어구 전환, 수정 방향 필터, 전체 보기, 항목별 TO-BE 복사
- AS-IS → TO-BE → 작성 틀 → 권장 위치 → 원문 근거·완료 기준
- 첫 화면 / 서비스 본문 / 근거 / FAQ·문의의 정보 배치 지도
- PDF 레이더 차트와 TO-BE 요약, 전체 단어/연속어구 상세 보존

## 검증 범위
기존 및 신규 회귀 테스트, 프로덕션 빌드, 운영 공유 화면과 PDF를 검증한다.
신규 테스트는 브랜드명·부정 조건 보존, 원문 미저장 처리, 의미 없는 빈도 임계값 배제, 전체 항목 보존과 PDF 페이지 경계를 확인한다.
이 작업의 클라우드 브라우저에는 뷰포트 변경 API가 없고 로컬 개발 화면도 연결 차단되어 모바일 실기기 시각 검증은 별도로 남는다. 코드에는 모바일 브레이크포인트와 터치 크기, 가로 넘침을 줄이는 minmax/줄바꿈 규칙을 반영했다. 검증용 임시 경로는 배포에 포함하지 않는다.
