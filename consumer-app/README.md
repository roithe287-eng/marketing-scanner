# 마케팅스캐너 포켓 · B2C 베타 0.1.0

기존 B2B 웹과 별도의 모바일 제품입니다. URL 1개를 점검하고 오늘 바꿀 세 가지, 현재 값, 공개 HTML에서 찾은 위치, 제작 도구별 수정 순서, 조건부 기대효과와 확인 지표를 제공합니다.

## 실행

```sh
cd consumer-app
npm ci
npm run dev -- --host 127.0.0.1
npm test
npm run build
npx cap sync
npm run native:android
npm run native:ios
```

- Android: Android Studio와 SDK 설치 후 프로젝트 열기. `android/gradlew assembleDebug`로 디버그 APK 생성. 현재 작업 환경에서는 Android SDK가 없어 바이너리 빌드는 검증하지 않았습니다.
- iOS: macOS/Xcode에서 `ios/App/App.xcodeproj` 열기. 개발자 팀과 서명 설정 후 실제 기기 빌드. 현재 환경에서는 iOS 컴파일·실기기 검증을 하지 않았습니다.
- 앱 ID: `com.prorealmkt.scanner.pocket`. 네이티브 프로젝트와 앱 아이콘을 포함합니다.

## 기능

- 문의·구매·검색 중 목표를 선택하는 URL 진단
- 공개 HTML 12개 규칙, 5개 영역 레이더 및 충족률
- 우선 개선 3개와 추가 확인 항목
- 실제 값 → 수정 예시 → 위치 → 단계 → 기대효과·한계·확인 지표 → 공식 출처
- 수정 완료 표시, 최근 40개 기록, 동일 URL·목표·방식의 이전 결과 비교
- 이메일 회원/체험 세션, 로그아웃, 개별 기록 삭제, 비밀번호 확인 후 계정 삭제
- 네이티브 공유·외부 브라우저·뒤로 가기·진동 연동

`src/demo.json`은 합성 HTML을 실제 점검 함수에 통과시켜 만든 예시입니다. 실제 고객 진단으로 저장하지 않으며 화면에 예시로 표시합니다. 실제 진단 실패를 예시로 대체하지 않습니다.

## 서비스 경계

- 프런트엔드: 별도 Vercel 프로젝트, 루트 `consumer-app`.
- 전용 API: 기존 서버의 `app/api/pocket/route.ts` → `consumer-app/server/handler.ts`.
- 웹 `/api/pocket`은 `vercel.json`에서 기존 서버의 전용 API로 프록시됩니다. 네이티브는 `https://www.mktscanner.com/api/pocket`에 직접 접속합니다.
- B2B 분석 API, IP 예외, 계정, 결제 권한, 보고서는 재사용하지 않습니다.
- Redis는 서버의 기존 연결을 사용할 수 있으나 키 공간은 `ms:pocket:v1:production:` / `preview:`로 분리합니다. 물리적으로 별도 데이터베이스라는 의미는 아닙니다. `POCKET_REDIS_REST_URL`과 `POCKET_REDIS_REST_TOKEN`을 함께 설정하면 별도 Redis로 분리할 수 있습니다.
- 웹 세션은 HttpOnly/Secure/SameSite 쿠키, 네이티브 토큰은 메모리에만 보관합니다. 네이티브 앱을 완전히 종료하면 재로그인이 필요할 수 있습니다. 영구 로그인은 추후 Keychain/Keystore 저장 구현 및 실기기 검증 후 활성화해야 합니다. 토큰을 localStorage/평문 Preferences에 저장하지 마세요.
- 공개 페이지 요청은 공인 주소 검사, DNS 고정 연결, 리다이렉트 재검증, 용량·시간 제한으로 내부망 접근을 차단합니다.
- 보고서는 세션 사용자 ID로 소유 범위를 결정합니다. 요청에서 전달된 사용자 ID를 신뢰하지 않습니다.
- 체험 1회/일, 회원 3회/일. 한국 시간 자정 기준. 실패한 분석은 사용자 할당량을 환불하며 남용 방지 요청 횟수는 별도 적용됩니다.

## 배포 환경 변수

기존 서버 프로젝트에 `POCKET_WEB_ORIGINS`를 쉼표로 구분한 **정확한 앱 origin** 목록으로 설정하세요. 와일드카드·임의 Origin 반사 금지. 환경 변수 변경은 새로운 서버 배포부터 적용됩니다.

선택 사항: 별도 Redis `POCKET_REDIS_REST_URL`, `POCKET_REDIS_REST_TOKEN` (서버만), 네이티브 API 서버 변경용 `VITE_API_ORIGIN` (공개 URL만). Redis 비밀 값은 `VITE_` 변수에 넣지 마세요.

## 베타 범위와 출시 전 남은 일

- 실제 검색 순위, 문의·매출 상승, AI 인용 실적을 측정하지 않습니다. 점수는 정적 HTML 확인 항목 충족률입니다.
- 기대효과는 공식 문서의 원리에 근거한 조건부 설명입니다. 해당 URL에서 실증된 효과·성과 보장을 의미하지 않습니다.
- 관리자 로그인, 위치 스크린샷, 자동 사이트 수정, 경쟁사 심층 비교는 포함하지 않습니다. 제작 도구 감지 역시 공개 흔적에 따른 추정입니다.
- 이메일 검증·비밀번호 재설정, 네이티브 보안 저장 기반 로그인 유지, 실기기 접근성/키보드/네트워크 복구 테스트는 출시 전 추가 구현·검증 대상입니다.
- 결제·구독은 비활성 상태입니다. 상용 요금·인앱 결제·스토어 개인정보 고지 및 처리방침은 출시 전 확정해야 합니다.
- Apple/Google 개발자 계정, 서명 인증서/키, 앱 심사 제출은 이 소스 구현과 별도입니다. 아직 스토어 등록된 앱이 아닙니다.

## 검증

`npm test`는 진단 근거, 관리자 경로의 조건부 매칭, SSRF 주소·DNS 방어, 비밀번호 검증, 소유자별 키, 허용 Origin을 확인합니다. 프런트엔드는 320/390/768/1440px에서 홈·결과·가이드·할 일·기록·가입 화면과 예시 완료 표시를 검증했습니다. 이 화면 검사는 로컬 예시 기반이며 실제 URL/Redis 동작 검증과 구분합니다.
